설정

물건 목록 (assets.seed.json)

시드를 바꿔도 저장된 관측은 지우지 않는다. 실제 시드 파일은 기기에서만 읽고 어디에도 보내지 않는다.

    필지 (연속지적도 경계·지번)

    PC 에서 j5 parcels convert 로 만든 .j5parcels.json 또는 파생본(j5 db project)의 parcels.geojson 을 넣는다. 파생본에는 정본에서 연결한 물건이 들어 있다. 기기에서만 읽고 어디에도 보내지 않는다. PNU 는 필지 ID 이고 물건(asset) ID 가 아니다.

    지도 (필지 경계·지번, 배경 타일 없음)

    외부 타일·통신 없음. 북쪽이 위. 점을 누르면 관측 기록, 필지를 누르면 아래에 지번·PNU 와 그 안의 물건이 뜬다. 확대하면 지번이 보인다. 지도가 안 보여도 위 목록에서 선택할 수 있다.
