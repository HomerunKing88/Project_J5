2. 사진 선택·형식·해시

확인할 것: iPhone이 HEIC를 JPEG로 바꿔 주는지, 보고된 type과 매직바이트 판정이 같은지, 큰 사진의 읽기·해시 시간.

3. 파일 저장

iPhone Safari는 공유 시트 또는 '파일' 앱 저장으로 이어진다. 실제로 어디에 저장됐는지 확인하고 아래에 표시한다.

저장한 파일을 '파일' 앱에서 열어 확인한 뒤 해당 항목을 체크하고 "결과 JSON 저장"을 한 번 더 누른다. 마지막 파일이 확인 상태까지 담은 최종 결과다.

4. VWorld 직접 연결 (J5-078)

폰에서 VWorld 를 바로 부를 수 있는지 본다. 인증키는 이 칸에만 두고 저장하지 않는다. 결과에는 키를 지운 주소만 남는다. 와이파이와 LTE/5G 에서 한 번씩 눌러 본다.

오른쪽 그림에 필지 경계선이 보이면 경계 그림 시험이 된 것입니다.
