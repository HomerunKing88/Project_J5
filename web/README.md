# web/

정적 앱. HTML·CSS·JavaScript ES Modules, 외부 통신 없음(각 페이지에 CSP `default-src 'self'`). 앱 실행에 Node.js·번들러를 요구하지 않는다. 외부 코드는 없다. 지도는 자체 SVG 점 지도(ADR-12, 배경 타일 없음)에 연속지적도 변환 번들의 필지 경계·지번을 겹친다(ADR-13). ZIP은 자체 작성기(ADR-11)다. MapLibre는 타일 이용조건이 확인되는 시점에 새 ADR로 검토한다. 실사진·실데이터·API 키는 넣지 않는다.

## 파일

- `index.html` + `app/main.js`: R1a 현장 기록 앱 (J5-006). 설정(study_id·자료 모드·경로 버전 ID) → 시드 불러오기(가상 5개 또는 기기의 파일) → 필지 번들 불러오기(선택) → 물건 선택(목록, 지도의 점, 또는 필지 탭 → 그 안의 물건) → 관측 저장(상태·시각/날짜·설명·사진·태그, 선택으로 촬영 지점·방향·이전 사진: 반복 촬영의 연차 비교용, J5-015B) → 저장 목록. 목록이 주 화면이고 지도가 실패해도 목록으로 동작한다.
- 연습용 모드(J5-077): 연습용 자료(가상 대상·필지·윤곽·거래)를 넣는 버튼·안내와 자료 종류의 연습용은 주소에 `?demo=1` 을 붙여 연 폰에서만 보인다(`?demo=0` 으로 끄고, 켬 여부는 IndexedDB meta `demo_mode`). 기본 자료 종류는 실제이고 실제 자료일 때는 상단 배지를 감춘다. 연습용 모드가 아닌 폰은 열 때마다 앱에 든 연습용 자료를 걷어 내며(연습용 자료 지우기와 같은 범위: 기록·사진·PC 자료 파일·이 폰이 만든 대상은 그대로), 자료 종류를 저장한 적 없으면 실제를 저장하고(PC 자료 파일을 처음 넣을 때 파일의 자료 종류를 그대로 받지 않게), 연습용으로 저장돼 있고 연습용 기록이 없으면 실제로 바꾼다(`ui.js` `retireModeTo`). 이미 실제로 저장된 폰은 연습용 모드를 켜도 실제 그대로이며 설정에서 연습용을 고른다. 서비스 워커는 페이지 열기 요청의 `?` 뒤를 빼고 캐시와 맞춰 `?demo=` 주소도 오프라인으로 열린다. e2e 는 `?demo=1` 로 시작한다.
- 화면 구성(J5-054, J5-020 을 재정리): 상단 바(앱 이름·자료 종류 배지·오프라인 배너) 아래 화면 3개를 하단 탭(넓은 화면은 상단 탭)으로 전환한다. **현장**(`#view-map`): 화면을 채우는 자체 SVG 지도(필지 경계는 지적 적색, 고른 대상·필지는 청색), 위에 지번 찾기 칸과 내 위치·전체·용도지역·실거래 버튼(J5-063: 거래 파일이 있을 때만 보인다. 켜면 아래에 값(총액·대지 평당·연면적 평당)과 기간(1·3·5년·전체) 줄이 나오고, 지번이 온전한 거래는 그 필지 위에 "근린 18.5억" 같은 꼬리표, 지번 일부가 가려진 거래는 번지대마다 점선 꼬리표 하나(후보 필지들 가운데, 필지 미확정)로 보인다. 꼬리표가 겹치면 최근 거래 것만 남는다. 필지 꼬리표는 필지 카드, 번지대 꼬리표는 그 번지대 거래 목록 카드를 연다. 종류(J5-066): 거래 파일에 종류가 둘 이상이면 모든 종류·상업·업무·단독·다가구·토지 중 고르는 칸이 나오며 주변 사례와 같은 선택을 쓴다. 켬·값·기간·종류는 이 폰에 저장), 오른쪽 확대·축소 아래 자리 고르기(십자 그림) 버튼(J5-062: 가운데 십자를 지도를 움직여 기록할 곳에 맞추고 "이 자리를 대상으로 기록", 필지 안이면 그 필지 카드, 밖이면 필지 번호 없는 이 폰의 대상을 만들고 바로 기록하기를 연다. 자료가 없고 배경 지도만 켰으면 지도는 종로5가역 부근에서 시작한다), 오른쪽에 확대·축소. 아래 시트(`#field-sheet`, `data-state` peek/open, 손잡이 `#sheet-toggle` 의 `aria-expanded`): 접힘에는 대상 수·기록 수·보낼 기록 수(형광펜)·기록 시작, 펼침에는 시트 위 카드 하나(고른 대상 카드: 이름·위치·마지막 기록·기록하기·이력·다른 지도에서 보기 / 필지 카드: 큰 지번·필지 번호·지목·속성·연도별 표(최근 5개 연도, J5-055)·최근 거래(같은 필지·확정 연결 거래 최근 3건, 번지대는 수만, J5-057)·주변 사례(J5-064, ADR-25: 거래 파일이 있을 때. 같은 시군구·법정동의 거래 수, 대지·연면적 평당 중간값과 범위, 공시지가 대비 배율 중간값, 배율 사례 3건부터 이 필지 공시지가 × 배율의 참고 추정, 최근 사례 5건, 기간은 지도 실거래와 같음. 거래 종류(J5-065: PC 파일의 `deal_kind` 로 토지·단독·다가구·주택, 없으면 건물 용도로 근린·업무 등)를 사례마다 적고, 토지 거래는 토지 면적으로 대지 평당·배율에 들며 연면적 평당에서는 빠진다. 종류 고르기는 지도 실거래와 같은 선택, J5-066. 추이 그래프(J5-067): 같은 동 거래의 대지 평당 점과 이 필지 공시지가 평당 환산 계단선을 한 축에, 점을 누르면 값, 그래프 값 표는 접힘. 연도별 시세(J5-071): 기간이 시작하는 해의 1월부터 올해까지 달력 연도마다 같은 동의 대지 평당 중간값 또는 거래 수 막대, 대지 평당 사례 3건 미만인 해·덜 받은 해와 올해는 테두리만, 사례 3건 이상인 해가 둘 이상이면 시작·최근 해의 중간값 변동, 연도별 값 표는 접힘. 받지 않은 해는 "미수집", 시도했으나 실패·부분만인 해는 "일부만 수집"(종류를 고르면 파생본의 종류별 시도 개월 `kind_months_any` 로 가르고, 그 칸이 없는 이전 파일은 "모름", J5-072·073). PC `db parcels-comps` 가 같은 값을 낸다)·공시지가가 바뀐 지점(접힘)·이 필지의 대상·필지 이력·이 필지를 대상으로 기록 / 처음이면 시작하기: PC 자료 파일 가져오기·연습용 자료로 둘러보기) 아래 대상 줄 목록(줄을 누르면 지도에서 고르고, 오른쪽 '기록' 은 바로 기록하기), 관찰목록 거르기, 조건으로 필지 찾기·지도 보는 법(접힘). 자료가 없거나 지도를 못 그리면 시트를 펼쳐 시작하기·목록을 보이고, 자료가 있으면 접어 지도를 보인다. 넓은 화면(900px 이상)에서는 시트가 오른쪽 420px 패널로 늘 펼쳐진다. 지도의 전체 보기·필지 맞추기·확대 중심·축척 막대·배경 타일 요청은 시트·찾기 칸에 덮이지 않은 영역 기준이다(`map.setInset`). **기록**(`#view-records`): 위에 PC 로 보내기(보낼 기록·사진·크기 요약, 4단계 표시: 확인 → 파일 만들기 → 파일 저장 → 저장 확인, 지금 단계의 버튼만 보이고 저장을 요청한 뒤에는 저장 확인과 다시 저장, 저장 확인 전에는 보낸 기록이 아니고 PC 반영·백업은 PC 에서 확인), 아래 이 폰의 기록(최근 것부터, 안 보냄/보냄 배지, 상태·본 시각·사진 수·메모). 기록 탭 배지는 안 보낸 기록 수다. **설정**(`#view-settings`): 자료 가져오기(PC 자료 파일 `.j5view.zip`: 대상·필지·PC 기록·거래 한 번에, 사진 제외, 정본 버전·만든 시각 표시. 연습용 자료 지우기(J5-061): 앱에 든 가상 대상·필지·윤곽이 있을 때만 보이며 그것만 지우고, 기록·사진·PC 자료 파일·이 폰이 만든 대상·다른 파일에서 가져온 자료는 그대로. 파일 하나씩 가져오기: 대상 목록·필지 경계·건물·도로 윤곽), 작업 공간(이름·자료 종류·조사 경로), 배경 지도(온라인 타일: 제공자·인증키(이 폰에만)·직접 입력(주소에 인증키처럼 보이는 값이나 z·x·y·key 밖의 `{ }` 가 있으면 저장하지 않고 키는 인증키 칸에 넣으라고 안내, J5-061), 저장된 타일 수·이 범위 미리 받기·지우기), 다른 폰이나 주소로 옮길 때·쓰는 순서·앱 정보(상태 줄·기기 시험 페이지)는 접힘. 예전 해시 `#home` 은 현장, `#export` 는 기록으로 연다. 기록하기는 전체 화면 작업 패널(`#sec-observe`, role=dialog): 대상 이름·위치 → '지난번과 비교하면' 큰 선택 3개(달라짐·그대로·확인 어려움, 저장 값 `change_observed`·`no_change`·`hard_to_confirm` 은 그대로) → 사진(무엇을 찍었는지, 반복 촬영 정보는 접힘) → 메모 → 본 시각(접힘) → 저장. 저장 뒤 완료 화면에서 다음 대상·지도로·기록 보기를 고른다. 화면 글은 사용자 말(대상·이 폰·보내기)과 존댓말로 쓰고, 오류는 무엇을 고치면 되는지 적는다. 이력 화면(`#sec-history`, role=dialog, J5-023)은 대상 줄·고른 대상 카드의 '이력', 필지 카드의 '필지 이력' 에서 열리며 연도별로 이 폰 기록·PC 기록·거래를 보인다(필지는 지번 일치 '이 필지' 와 지번 일부 마스킹 '번지대' 를 구분. 필지 이력 위에는 연도별 요약 표(J5-047, 표는 J5-055: 연도·공시지가와 전년 대비·이 필지 거래 수와 번지대·연결·수집 개월·소유 변동, 줄의 title 에 이 폰의 요약 글 한 줄, PC 와는 칸의 값으로 대조): 그 연도 기준 공시지가·전년 대비, 이 필지에 닿는 같은 필지·번지대 거래 수와 그 시군구의 수집 개월. 수집하지 않은 해·실패만 있는 해·거래 범위 밖 동(규칙에 시군구가 있으면 다른 시군구의 같은 이름 동 포함, J5-048)·수집 현황이 없는 이전 파일은 0 이 아니라 사유로 적는다. 그 연도의 소유 변동일(파생본 현재 속성과 토지소유 변화 항목에서, 토지소유 자료가 없으면 "소유 자료 없음", J5-053). PC `db parcels-years` 와 같은 규칙. 파일의 수집 개월에 종류별 개월(`kind_months`, J5-065)이 있고 종류·개월이 고르지 않은 해는 거래 수 칸에 "상업·업무만" 이나 "상업·업무 12 · 토지 1개월" 처럼 적는다). 저장 실패·필수값 누락·미지원 사진·크기 초과·중복 사진은 입력 화면에 오류로 남고 저장한 것으로 표시하지 않는다. 내부 용어(study_id·data_mode·route_version_id·origin·해시)는 설정 힌트와 고급 정보에만 둔다. 화면 전환·요약 계산은 `app/ui.js`(순수 함수 + 전환기)에 있다.
- `app/vworld.js`: 온라인 필지 조회(J5-080, ADR-27). 지도의 빈 곳을 누르면 격리 프레임(`vworld-frame.html`, sandbox)이 VWorld 연속지적·용도지역을 JSONP 로 부르고(`createVworldBridge`), 응답을 해석해(`parseParcelResponse`: 실측 필드 pnu·addr·jibun·jiga·gosi_year·gosi_month, 지번 뒤 글자를 지목으로, 도형면적 계산 / `parseZoningResponse`: 속성 이름 그대로) 현장 시트의 조회 카드와 지도의 조회 필지 층(`map.setLookup`)에 보인다. 키는 배경 지도의 VWorld 키, 결과는 저장하지 않는다. 화면 범위의 필지(J5-081): VWorld 기본 지도·확대 17단계 이상에서 멈춘 뒤 보이는 범위의 연속지적을 범위로 받아(`parseParcelsInBox`, `aroundQueryBox`) 지도의 주변 필지 층(`map.setAround`)에 경계·지번을 그린다. 카드의 용도지역은 실측 필드로 한 줄(`zoningSummary`). 주소 찾기(J5-082): 찾기 칸은 가져온 필지에서 먼저 찾고 없으면 VWorld 주소 검색(`bridge.search`, `parseSearchResponse`, 응답 필드는 실측 전)으로 찾아 그 자리로 옮기고(`map.centerOn`) 필지를 조회한다.
- `app/tiles.js`: 배경 지도 타일(J5-024, ADR-18) 계산·URL. 제공자 미리 설정(VWorld 3종, 직접 입력. VWorld 기본 지도는 실기기 확인 뒤 켬, 항공사진 두 가지는 확인 전, J5-079), 템플릿 검사(허용 호스트 `api.vworld.kr` 또는 같은 출처 `./`), 확대 단계, 화면을 덮는 타일 목록, 미리 받기 계획(범위·단계·상한). DOM·통신 없음. 요청 자체는 `map.js` 의 `<image>` 가 내고 `sw.js` 가 캐시(`j5-tiles-v1`)한다.
- `app/unzip.js`: 조회 파생본 `.j5view.zip` 읽기(J5-023, ADR-17). 중앙 디렉터리 파싱, 허용 이름 목록·경로 탈출·암호화·심볼릭 링크·중복·한도 검사, STORED/DEFLATE(`DecompressionStream`) 해제, CRC·크기·manifest sha256 대조. 사진 항목은 읽지 않는다.
- `app/view.js`: 파생본 manifest·기록·거래 검증, 금액 표기, 지번 대조(이 필지/번지대/동 전체 마스킹 제외, 실제 표기 `1**`·`16*-3` 처럼 자릿수를 가린 지번은 자릿수 범위로. ## 시험용으로 열기

PC에서 저장소 루트 기준으로 정적 서버를 띄우고 같은 Wi-Fi의 폰에서 연다.

```text
python -m http.server 8000 --directory web
```

- `http://<PC IP>:8000/`은 비보안 컨텍스트라 `crypto.subtle`·서비스 워커가 없다. 해시는 순수 JS 폴백으로 계산하고, 앱 캐시(오프라인 실행)는 HTTPS 에서만 동작한다.
- 해시·오프라인·현재 위치까지 쓰려면 HTTPS가 필요하다. 아래 "배포" 의 Cloudflare 주소로 연다(ADR-24). 실데이터는 어떤 경우에도 올리지 않는다.

## 배포 (Cloudflare, ADR-24)

폰에서는 `https://j5.<도메인>/`(이 프로젝트는 `https://j5.dooduk.com/`) 으로 연다. 게시되는 것은 `web/` 폴더(코드·문서·가상자료)뿐이고 실데이터는 올리지 않는다. 처음 한 번은 사용자가 계정에서 설정한다.

1. Cloudflare 계정을 만든다(무료).
2. Workers & Pages → 만들기 → GitHub 연결 → `HomerunKing88/Project_J5` 만 접근 허용. 프로젝트 이름은 `project-j5`(저장소의 `wrangler.jsonc` 의 `name` 과 같아야 한다).
3. 빌드 설정: 빌드 명령 없음, 배포 명령 `npx wrangler deploy`, 루트 디렉터리 `/`, 운영 브랜치 `main`. 배포 명령은 저장소 루트의 `wrangler.jsonc` 를 읽어 `web/` 만 올린다. 빌드 기록에 `Read 34 files from the assets directory …/web` 처럼 `web` 폴더가 보이면 맞다(파일 수는 앱 판마다 다르다). 배포가 끝나면 `project-j5.<계정>.workers.dev` 주소가 생기니 폰에서 먼저 열어 본다.
4. 사용자 지정 도메인: 프로젝트 → 설정 → 도메인 및 경로 → 추가 → 사용자 지정 도메인 `j5.<도메인>`. Workers 는 도메인이 Cloudflare 의 DNS 영역이어야 한다. 도메인 추가(사이트 추가)로 `dooduk.com` 을 Cloudflare 에 넣고, 도메인을 산 곳에서 네임서버를 Cloudflare 가 알려 준 두 개로 바꾼다. 바꾸기 전에 기존 DNS 기록(루트·`www`·메일 MX 등)이 Cloudflare 로 옮겨졌는지 확인한다. DNS 를 옮기지 않으려면 Workers 대신 Pages 프로젝트(Git 연결, 빌드 출력 `web`)를 만들고 바깥 DNS 에 CNAME(`j5` → `<프로젝트>.pages.dev`)을 넣는다. HTTPS 는 어느 쪽이든 자동으로 붙는다. 이 앱은 `j5` 한 줄만 쓰므로 루트·`www` 의 연결은 따로 정리해도 된다.
5. (선택) 접속을 본인으로 제한: Zero Trust → Access → 애플리케이션 추가 → `j5.<도메인>` 에 본인 메일만 허용.
6. 옮기기 전에 예전 주소(`http://<PC 주소>:8000`)에서 남은 기록을 모두 PC 로 보내고 PC 반영을 확인한다. 새 주소에서 설정의 작업 공간 이름을 저장하고 PC 자료 파일을 다시 가져온다.
7. 배경 지도(VWorld) 키를 쓰면 VWorld 에 `https://j5.<도메인>` 을 서비스 URL 로 등록한다.

이후에는 `main` 에 머지할 때마다 자동으로 다시 게시된다. 배포 설정은 `wrangler.jsonc`, 응답 헤더는 `web/_headers`, 게시 대상 검사는 `tests/test_web_publish.py`, 공급자의 `index.html` 넘김은 `tests/web/deploy.e2e.test.mjs` 가 흉내 내어 확인한다.
