# 종로5가 투자지도 개발기준 v1.2

기준일: 2026-09-22. 상태: 개발 전 문서 개정. 실제 저장소·코드·계정은 변경하지 않았다.

|---|---|---|

## 유지하는 기능

시간 조회의 관측 기준·당시 기록 기준 분리, 목표 매수가 수정 이력, `field_path`별 근거, 구조화 투자판단, 반복 사진, 자동·반자동·수동 출처 분류는 유지한다. 정본 기록과 원본 자료를 불변 이력으로 남기고, 잘못 저장한 개인정보는 예외적으로 실제 삭제한다.

`용적률 기준 여유면적`은 개발 검토 보조값으로 유지한다. 출회 확률·종합점수·자동 저평가 판정은 구현하지 않는다. 가계 자산축적 대시보드는 외부 스프레드시트에 둔다.

## 첫 사용과 운영 완성의 구분

R1a에서 소수 물건을 대상으로 사진·관측을 기록하고 ZIP 한 개로 내보내 실제 임장을 시작한다. PC에서 파일과 사진을 열어 확인하고 별도 사본을 만든다. 이 단계는 정본 반영 전 수집 시험 단계다.

R1b에서 SQLite 정본 반영·재반영 방지·일관된 백업·복구를 완성한다. 일반 운영은 R1b 통과 후 시작한다. R1a 기록은 동일 포맷으로 소급 반영하며 `recorded_at`은 실제 정본 반영일을 사용한다.

## 출처와 검증 범위

검토 기초는 제공된 개발계획서 v1.0 전체와 사용자가 제공한 클로드 검토문이다. 외부 확인 자료는 [ADR의 근거 목록](docs/ADR.md#공식-확인-자료)에 정리했다. 실제 API 인증 호출, 종로5가 전수 집계, 특정 필지 법률 판단, 사용자 기기 실험, 구현 소요시간 실측은 수행하지 않았다.

숫자 예시는 모두 가상 계산 또는 개발 예산이다. 현재 부동산 가격·은행 승인·세율·미래 수익률을 뜻하지 않는다.

## 변경 관리

- 기능·구조 결정은 ADR, 값·계산 계약은 데이터 사전, 일정·작업은 릴리스 계획에서 한 번만 정의한다.
- 실제 SQL·JSON Schema 구현 후 자료형·필수값은 실행 스키마가 검증하고 문서는 의미·근거·예외를 설명한다.
- 구현과 문서가 충돌하면 PR을 완료하지 않는다. 스키마 변경에는 마이그레이션과 테스트를 붙인다.
- 구현하지 않는 후속 기능의 빈 테이블·화면·추상 프레임워크를 미리 만들지 않는다.
