# J5-078 온라인 필지 조회 (1단계: VWorld 연결 시험)

기록일: 2026-10-14. 사용자 결정: 폰 지도에서 필지를 바로 조회하는 온라인 방식으로 전환("온라인 조회로 전환 (추천)"), Cloudflare 에 VWorld 키를 비밀값 `VWORLD_API_KEY` 로 등록. 설계 결정은 ADR-27(시험 결과 뒤), 이번 단계는 ADR-24 보정.

## 배경

- 클라우드 작업 환경에서 VWorld 를 재려고 새 세션(환경 변수·네트워크 허용 반영)을 열어 8가지 요청을 보냈으나 모두 `502 Bad Gateway`·빈 응답이었다. 키 없는 요청도 같았다. 프록시는 `api.vworld.kr` 연결을 열었고(다른 호스트는 403) 502 는 VWorld 형식이 아니어서, VWorld 가 해외 IP 접속을 막는 것으로 추정한다(미검증). 이 작업 환경은 해외에서 나간다.
- 같은 차단이 Cloudflare Worker 에도 걸리면 Worker 를 거치는 구조는 쓸 수 없고, 폰(국내 회선)이 VWorld 를 직접 불러야 한다. 그때는 브라우저의 다른 출처 요청 허용(CORS)이 필요하다. 두 가지를 실제로 재고 나서 구조를 정한다.

## 결과

- `worker/index.js`(새 파일): `/api/vworld/probe` 가 고정 지점(종로5가역 부근)으로 연속지적(`LP_PA_CBND_BUBUN`)·용도지역(`LT_C_UQ111`)을 부르고, PNU 를 얻으면 토지특성·토지임야·개별공시지가·토지이용계획(NED)을 부르며, 배경 타일(WMTS Base z17) 하나를 받는다. 단계마다 HTTP 상태·시간·형식·바이트·`access-control-allow-origin`·본문 앞 6,000자(키 지움)를 돌려준다. 같은 시험은 5분 동안 Cloudflare 캐시의 결과를 준다. 응답에 Cloudflare 처리 위치(`colo`)·나라를 싣는다. 그 밖의 `/api/` 는 404, `/api/` 밖은 정적 자산 그대로.
- `wrangler.jsonc`: `main: worker/index.js`, `assets.binding: ASSETS`, `assets.run_worker_first: ["/api/*"]`. 환경 값(vars)은 두지 않는다.
- 기기 시험 페이지(`devtest.html`): "4. VWorld 직접 연결" 에 인증키 칸(저장하지 않음)과 시험 버튼. 폰에서 필지 조회(다른 출처 요청)와 배경 타일(그림)을 한 번씩 부르고 결과 JSON 에 키를 지운 주소·상태·응답 필드 이름을 남긴다(`app/vworldtest.js`). 이 페이지의 CSP 만 `connect-src`·`img-src` 에 `https://api.vworld.kr` 를 연다. 앱(index.html)의 CSP·코드는 바꾸지 않았다.
- 시험
  - `tests/web/worker.test.mjs`(새 파일): 키 지우기, PNU 찾기, `/api/` 밖은 정적 자산·모르는 `/api/` 는 404, 키 없으면 500, 응답·주소에 키 없음, PNU 를 얻으면 토지 자료까지 부름, 타일 본문은 싣지 않음, VWorld 에만 요청, 연결 실패도 키 없이 사유.
  - `tests/test_web_publish.py`: 배포 설정에 Worker 코드(web/ 밖)·`/api/*` 만·코드에 키 없음.
  - `tests/test_web_static.py`: VWorld 시험 모듈의 호스트는 `api.vworld.kr` 하나, `fetch` 는 `parcelProbeUrl` 로 만든 주소만, devtest.html CSP 의 VWorld 항목.

- 리뷰 반영(PR #125, Codex 3건)
  - 앱의 서비스 워커가 `api.vworld.kr` 로 가는 모든 요청을 맡아 no-cors 로 다시 보내, 앱을 한 번 연 폰(배포 주소의 보통 흐름)에서는 기기 시험 페이지의 필지 조회가 VWorld 의 허용 여부와 상관없이 막힘으로 적혔다. 같은 이유로 실제 키가 든 시험 타일 주소가 타일 캐시에 남았다. 서비스 워커는 다른 출처 요청 가운데 키 자리표가 든 앱의 타일 요청만 맡는다(앱 0.2.38). 시험: `tests/web/vworldtest.e2e.test.mjs`(서비스 워커를 설치한 뒤 기기 시험 페이지에서 VWorld 응답을 CDP 로 흉내 내어 필지 조회 ok·타일 ok·결과와 타일 캐시에 키 없음). 고치기 전 서비스 워커로 돌리면 실패한다.
  - 시험 주소가 공개라 Cloudflare 캐시가 비어 있을 때 동시에 불리면 요청마다 VWorld 를 3~7번씩 불렀다. 같은 Worker 실행체 안에서는 시험을 한 번에 하나만 돌리고 끝난 결과를 5분 동안 다시 쓴다. 시험: 동시에 5번 불러도 VWorld 호출 3번, 다시 부르면 `reused`.

## 실측 결과 (2026-10-14, PR #125 배포 뒤)

- Cloudflare Worker `/api/vworld/probe`(사용자가 비밀값을 빌드 변수가 아닌 실행 변수로 다시 넣은 뒤): `colo` NRT(도쿄), `country` KR. 연속지적·용도지역·배경 타일 셋 다 HTTP 520(`error code: 520`, 본문 16바이트), 0.6~1.0초. VWorld 가 해외 서버 연결을 끊는 것으로 본다(클라우드 작업 환경의 502 와 같은 결과). PNU 를 얻지 못해 토지 자료 단계는 돌지 않았다.
- 폰(iPhone, iOS 18.7, Safari, 배포 주소, 기기 시험 페이지 4번): 배경 타일 ok(256×256, 65ms), 필지 조회 직접 호출 `cors_blocked_or_network`(`Load failed`, 185ms). 데이터 API 가 다른 출처 허용 머리글을 주지 않는 것으로 본다(응답을 읽을 수 없어 확정은 아니다).
- 판단: Worker 를 거치는 구조는 쓰지 않는다. 배경 지도는 폰에서 바로 그릴 수 있다. 데이터 API 는 다른 길이 필요하다.

## 1단계 b: Worker 제거, 격리 프레임 JSONP·경계 그림 시험

- Worker 코드(`worker/index.js`)·시험(`tests/web/worker.test.mjs`)을 지우고 `wrangler.jsonc` 를 정적 자산만으로 되돌렸다. Cloudflare 의 비밀값 `VWORLD_API_KEY` 는 쓰지 않는다(지워도 된다).
- 격리 프레임 `web/vworld-frame.html` + `web/app/vworld-frame.js`: 부모가 `sandbox="allow-scripts"`(같은 출처 권한 없음)로 넣으므로 이 안의 스크립트는 앱의 IndexedDB·쿠키에 닿지 못한다. 프레임은 부모가 보낸 값(요청 번호·키·도메인·자료 이름·경도·위도)을 검사해(자료는 연속지적·용도지역만, 좌표는 한국 범위) VWorld 데이터 API 주소에 `callback` 을 붙여 스크립트로 부르고, 받은 응답을 JSON 으로 한 번 복사해 부모에게 보낸다. 키는 돌려보내지 않는다. 프레임 CSP 는 스크립트만 자기 자신과 VWorld, 통신·그림·스타일은 없음. 같은 출처 권한이 없는 틀은 모듈 스크립트를 읽지 못해 일반 스크립트 하나를 쓴다.
- `web/_headers`: 격리 프레임 두 주소(`/vworld-frame.html`, 공급자가 넘기는 `/vworld-frame`)만 앞 규칙의 틀 금지를 떼고(`! Content-Security-Policy`, `! X-Frame-Options`) 같은 출처의 틀을 허용한다.
- 기기 시험 페이지 4번: 직접 호출·배경 타일에 더해 격리 프레임 JSONP 필지 조회와 연속지적 경계 그림(WMS GetMap, 시험 지점 z17 타일 범위)을 본다. 경계 그림은 화면에 보여 사용자가 선이 보이는지 확인한다.
- 시험: `tests/web/vworldtest.e2e.test.mjs` 에 격리 프레임 JSONP(다른 프로세스의 틀에도 CDP 가로채기를 켜 VWorld 응답을 흉내)·경계 그림·시험 뒤 프레임 지움. `tests/test_web_static.py` 에 격리 프레임 CSP·호스트·만드는 주소·저장소 API 금지, 어느 파일도 `allow-same-origin` 을 주지 않음, 프레임에서 온 메시지만 받음. `tests/test_web_publish.py` 에 틀 허용은 격리 프레임 주소만. `tests/web/cdp.mjs` 에 세션 지정 명령.
- 시험 결과: `python -m pytest -W error::UserWarning` → 474 passed (66초), `node --test --test-timeout=300000 "tests/web/**/*.test.mjs"` → 106 pass.
- 미확인: VWorld 데이터 API 가 `callback`(JSONP)을 실제로 받는지, 배포 공급자가 `_headers` 의 `!` 떼기를 적용하는지(안 되면 격리 프레임이 틀 금지로 열리지 않아 `timeout` 으로 적힌다).

## 미확인 변수

- Cloudflare Worker 에서 VWorld 를 부를 수 있는지(해외 접속 차단 여부). 머지·배포 뒤 `https://project-j5.j5map.workers.dev/api/vworld/probe` 로 잰다.
- 폰(국내 회선)에서 VWorld 데이터 API 의 다른 출처 요청이 허용되는지, 타일이 그려지는지. 기기 시험 페이지로 잰다.
- VWorld `domain` 값의 형식(주소 그대로인지 호스트만인지), 응답 필드 이름, 호출 한도·이용약관의 캐시 범위.

## 남은 인수조건·후속 작업

- (1단계 a 기록) 사용자: 머지 뒤 (1) 폰이나 PC 브라우저로 `https://project-j5.j5map.workers.dev/api/vworld/probe` 를 열어 내용을 복사해 준다(키는 지워져 있다). 이 작업 환경의 네트워크 허용 목록에 `project-j5.j5map.workers.dev` 를 더하면 직접 읽을 수 있다. (2) 폰에서 `https://project-j5.j5map.workers.dev/devtest.html` 의 4번에 VWorld 키를 넣고 와이파이와 LTE/5G 에서 한 번씩 눌러 결과 JSON 을 복사해 준다.
- 사용자(1단계 b): 머지 뒤 폰에서 기기 시험 페이지 4번을 다시 눌러 결과 JSON 을 공유하고, 경계 그림에 필지 선이 보이는지 알려 준다.
- 결과로 ADR-27 을 정하고 2단계(지도 탭 → 필지 경계·속성, 기본 배경 지도)를 만든다.
