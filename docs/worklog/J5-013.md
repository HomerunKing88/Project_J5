# J5-013 필지·건물·조사경로·표본

기록일: 2026-09-23. 이 작업은 두 부분으로 나눈다. **A**(이 기록): 조사 경로·점포·표본틀·세션·점포 관측·공실 집계(데이터 사전 §5, ADR-04). **B**(별도 PR): 필지·건축물 정규화와 허용된 외부 자료 수집(§6·§2). B 는 공식 API 승인·실제 파일 확인이 먼저라 코드만으로 완료할 수 없다.

## A. 결과

- db_schema 4 (`r2_survey`): `survey_routes`, `survey_route_versions`(순서 있는 구간 목록 JSON, 버전 번호, `previous_version_id`, 변경 사유, 내용 해시), `survey_units`(subjects 의 `survey_unit` 자식, 물리적 위치·층·좌표·연결 asset_id·생성·종료일), `survey_unit_links`(분할·통합), `survey_frame_versions` + `survey_frame_members`, `survey_sessions`(방문·건너뜀 구간, 누락 사유), `unit_observations`((session_id, unit_id) PK, 상태 6종, 업체명·업종은 관측값, 선택 `record_id`), `record_survey_refs`(관측 이벤트의 `route_version_id`·`frame_version_id`, records 불변이라 별도 테이블, 마이그레이션이 기존 대장 행 바이트에서 소급 채움, 외래키 없음).
- `j5/db/survey.py`: `apply_input`(파일 4종, 한 트랜잭션, 멱등, 불변 위반 거절, 참조 검사, 정본 변경 시 dataset_version +1), `vacancy`(N·K·V·비율·미확인·미조사·표본틀 밖), `compare`(공통 확인 점포·단절·전체 값 분리), `overview`. 반영기(J5-010)가 새 이벤트의 경로 참조를 `record_survey_refs` 에 남긴다.
- CLI `j5 db survey-apply / survey-vacancy / survey-compare / survey-overview`. 스키마 `schemas/survey_input.schema.json`. 예제 `tests/fixtures/survey/` 8종(경로 v1·v2, 점포 v1·v2, 표본틀 v1·v2, 세션 1·2) — J5-006A 의 실제 경로 파일 형식으로 쓴다.
- 테스트 `tests/test_j5_013_survey.py` 7건. 전체 pytest 192건 통과.

## 데이터 사전에 없어 정한 값

- 입력 형식은 JSON 파일 4종(§5 "경로와 표본의 수동 편집으로 충분"). 구간은 `segment_id`(영숫자·`-`·`_`)와 이름·시작·끝 설명이며 도형·좌표는 두지 않는다.
- 경로 버전·표본틀 버전·세션·점포 관측은 불변이다. 같은 ID·다른 내용은 거절이며 수정은 새 버전(`previous_version_id`, `change_reason` 필수)·새 세션이다. 세션에 관측을 나중에 더하는 것(새 unit_id)은 허용한다.
- 점포 관측 상태 `occupied / vacant / closed_today / lease_ad_only / not_visited / unclear`. K 는 앞의 둘. 표본틀에 있으나 관측 행이 없는 점포는 "기록 없음(미조사)" 로 따로 센다. 표본틀 밖 점포의 관측은 저장하되 분모에 넣지 않는다.
- 시점 비교의 단절: 두 세션 시작일 사이(`effective_from`)에 분할·통합 링크가 걸린 점포(이전·새 단위 모두)는 공통 표본에서 빼고 목록으로 표시한다. 종료된 점포(`closed_on`)라도 표본틀에 남아 있으면 N 에 포함된다(표본틀을 새 버전으로 바꾸는 것이 원칙).
- `record_survey_refs` 는 외래키가 없다. 폰이 먼저 적은 경로 버전 ID 가 정본에 아직 없을 수 있어 반영을 막지 않고, `survey-overview` 가 "정본에 없는 경로 버전 참조 n건" 으로 표시한다.
- 조사 자료는 백업(J5-012)에 자동 포함되고 파생본(J5-011)에는 넣지 않았다. 폰에서 표본·세션을 보는 기능은 R2 의 "읽기용 테이블·실제 필요 확인" 이후.
- 보행량(§5 마지막 단락)은 이 PR 에 없다. 세션 `note` 로만 남길 수 있다.

## 공수

- 예상(J5-013 전체) 10~16시간. A 실제(세션 기준) 약 1시간.

## 미확인 변수·남은 인수조건

- J5-013B: 필지(공부면적·도형면적·CRS·도형 버전·주소 확인 상태)·건축물(총연면적·용적률 산정용 연면적 등, 총괄/개별 대장 분리)·`asset_components`/`building_parcels`. 공식 API·허용 파일 확인 후 진행.
- 실제 경로·점포 파일(J5-006A)은 사전 답사 후 사용자가 만든다. 이 PR 의 예제는 형식 안내용 가상자료다.
- R2 인수 "파생본 실패 후 정본·이전본의 버전이 그대로 표시된다" 는 J5-011 에서 확인했다.
