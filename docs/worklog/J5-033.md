# J5-033 조건으로 필지 찾기

기록일: 2026-09-28. 폰에는 필지 2,700여 개의 토지 자료(용도지역·공부면적·공시지가·소유구분·지역지구 관계)가 들어 있지만, 필지를 찾는 길은 지번·PNU 검색(J5-027)과 지도에서 누르기뿐이었다. 투자 후보를 좁히려면 "상업지역이면서 공부면적 300㎡ 이상" 같은 조건 검색이 필요해 지도 화면에 더했다. 번들 안에서만 거르며 외부 통신은 없다. 가상자료로 시험했다.

## 결과

- `web/app/parcels.js`: `parseFilter`(폼 값 → 조건. 공시지가는 만원/㎡ 로 받아 원/㎡ 로 바꾼다. 음수·숫자 아님·거꾸로 된 범위는 오류), `hasCriteria`, `filterParcels`(모든 조건을 만족하는 필지. 값이 없는 필지는 맞는 것으로 보지 않고 용도지역·공부면적·공시지가·소유구분·규제별로 따로 센다. 공부면적 큰 순, 같으면 PNU 순, 앞 50개), `ownershipKinds`(번들의 소유구분 값과 수), `filterRowText`(결과 한 줄: 용도지역 · 공부면적 · 공시지가 · 소유구분, 없으면 미확인).
- `web/app/map.js`: `setMarked(pnus)` 가 맞는 필지 테두리를 강조한다. 번들이 바뀌면 지운다.
- `web/index.html`·`main.js`·`styles.css`: 지도 화면의 필지 찾기 아래 접히는 "조건으로 필지 찾기"(필지 속성이 있는 파일에서만 보임). 용도지역 분류·공부면적 최소/최대(㎡)·공시지가 최소/최대(만원/㎡)·소유구분(번들 값과 수)·저촉 규제 있음. 찾기 → "속성 있는 필지 N개 중 M개 일치 (공부면적 큰 순) · 지도에 테두리로 표시 · 값 없는 필지: 공시지가 k …", 목록에서 "열기" 로 필지 패널. 지우기 → 폼·목록·강조 해제. 잘못된 조건이면 안내하고 강조를 지운다. 리스너는 지도 초기화 밖이라 지도가 실패해도 목록은 동작한다. 앱 0.2.12, SW 캐시 v0.2.12.
- 같은 PR 에 J5-032 리뷰 반영(옛 형식 번들이 정정된 이름을 지우지 않게)을 따로 커밋했다(작업 기록 J5-032).
- 테스트: `tests/web/parcels.test.mjs` 1건(조건 해석·거르기·결측 세기·정렬·결과 글), `app.e2e.test.mjs` 조건 찾기 절(상업 1필지·테두리 1개·열기, 저촉 3필지, 잘못된 범위 안내·강조 해제, 지우기).
- 문서: 릴리스 계획 §10 J5-033, `web/README.md`, 색인(J5-032 PR #79).

## 데이터 사전에 없어 정한 값

- 조건 항목과 단위: 용도지역은 J5-025 의 색 분류 8종, 면적은 공부면적(토지대장, 도형면적 아님) ㎡, 공시지가는 만원/㎡ 입력.
- "저촉 규제 있음" 은 지역지구 관계 중 저촉이 하나라도 있는 필지다(접함은 넣지 않는다).
- 결과 목록 상한 50개, 지도 강조는 일치 전체.
- 결측 집계(리뷰 반영 PR #80): 켠 조건마다 그 값이 없는 필지 수를 다른 조건 결과와 상관없이 센다. 따로 "값이 없어 맞는지 모르는 필지"(확인된 불일치 없이 결측이 있는 필지) 수를 보이고 결과에서 뺀다.
