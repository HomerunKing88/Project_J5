# J5-025 VWorld 토지 자료 묶음 자동 인식과 필지 속성

기록일: 2026-09-27. 사용자가 VWorld 에서 내려받은 3개 구역의 토지 자료(연속지적도형정보·토지특성·토지이용계획·토지소유공간정보)를 보내며 "이 정보들을 베이스로 기본 지도에 연결하고 개별 정보를 쌓아나가면 다른 지역도 용이하지 않을까" 라고 제안했고, 가장 효율적인 순서로 판단해 진행하기로 했다. ADR-19 로 채택했다. 실제 자료·번들은 작업 환경의 임시 폴더에서만 다뤘고 저장소에 넣지 않았다.

## 결과

- `j5/parcels/vworld.py`(새): VWorld 묶음 인식(`detect_vworld`: 바깥 ZIP → 안쪽 자료별 ZIP 을 임시 폴더에 안전 추출(경로 탈출·크기·압축비·중복 자료 검사) / 자료별 ZIP·SHP 하나 → 같은 폴더·상위 폴더의 형제 자료 / 풀어 둔 폴더), `변경컬럼정보.csv` 매핑(`read_mapping`, UTF-8 BOM·CP949, 한 폴더에 여러 CSV 면 같은 자료 코드의 것), 속성 읽기(`read_attrs`: 토지특성·토지이용계획·토지소유 → PNU 별 `attrs`, 출처 목록). 연령대·거주 구분(`PRIVATE_FIELDS`)은 행에서 빼고 읽는다. '지정되지않음'·빈 값은 null.
- `j5/parcels/convert.py`·`j5/cli.py`: `ConvertOptions.field_map`(열 이름 되돌리기)·`attrs_by_pnu`·`attrs_sources`, `inspect_source(field_map=)`, 지번 필드 후보에 `lnm_lndcgr_smbol`. CLI 는 `parcels inspect/convert` 입력이 VWorld 묶음이면 자동으로 매핑·UTF-8·속성을 적용하고(`--no-land-attrs` 로 끔) 끝나면 임시 폴더를 지운다. `inspect --json` 에 `vworld` 항목.
- `schemas/parcels_bundle.schema.json`: 필지마다 선택 `attrs`(`$defs/attrs`, 추가 필드 불가), 최상위 선택 `attrs_sources`.
- 정본(`j5/db/schema.py` 마이그레이션 15 `parcel_attributes`, `j5/db/parcels.py`): `parcels-load` 가 속성을 필지마다 한 행으로 넣는다(같은 내용 변화 없음, 같거나 새로운 기준일이면 갱신, 오래된 기준일 거절). 공부면적은 `parcels.registered_area_m2` 에 채우고 사유를 지운다. 출처 문서 비고에 속성 자료명·해시를 적는다. 같은 기준일에 도형·지번은 같고 자료명·파일 해시만 다르면 변화 없음(구역을 나눠 받은 경계 필지). 파생본 `parcels.geojson` 에 `attrs`·`attrs_sources`(자료 종류·dbf 해시로 중복 제거). `db status` 행 수에 `parcel_attributes`.
- 폰(`web/app/parcels.js`·`map.js`·`main.js`·`index.html`·`styles.css`): 번들 검증에 `attrs`·`attrs_sources`(허용 필드만), 필지 패널에 항목 목록(지목·공부면적·공시지가와 기준 연월·용도지역·이용상황·도로접면·지형·규제·지역지구(잘림 표시)·소유구분·공유인수·변동일, 결측은 "미확인")과 안내 문구, 지도의 "용도지역 색" 버튼(속성 있는 번들에서만, 켬 여부는 IndexedDB meta `zone_colors`, 범례에 분류별 수), 자료 관리 안내에 "필지 속성 N개 (자료명)". 앱 0.2.5, SW 캐시 v0.2.5.

## 실측 (사용자 제공 VWorld 3구역, 작업 환경 임시 폴더)

- 형식: 바깥 ZIP 안에 `<번호>_<시각>_dt_d002_연속지적도형정보.zip`·`dt_d154_토지이용계획공간정보.zip`·`dt_d160_토지소유공간정보.zip`·`dt_d194_토지특성공간정보.zip`. 각 ZIP 에 .shp/.shx/.dbf/.prj/.qix/.fix 와 `dt_dNNN_변경컬럼정보.csv`(UTF-8 BOM, `원본컬럼명,변경컬럼명`). .dbf 열 이름은 A0…An 이고 자료마다 순서가 다르다(d002 pnu=A10, d194 pnu=A22, d154 pnu=A9, d160 pnu=A14). 인코딩 UTF-8(.cpg 없음, CP949 로는 실패), EPSG:4326, 열 길이 254.
- 변환: 3구역 724·552·1,448필지, 속성 100% 부착. 실행 `python -m j5 parcels convert <ZIP> --out … --geometry-version 2026-09-05 --source-name … --bbox <inspect 의 bbox_wgs84>`. 지역지구 이름 목록은 모든 필지에서 잘렸고(코드 11~18개, 이름은 약 8개까지) 코드 목록은 온전했다. 용도지역: 구역 1·2 는 일반상업지역, 구역 3 은 제1·2·3종일반주거·일반상업 혼재. 소유구분: 개인·법인·국유지·외국인·비법인, 빈 행 약 1/3.
- 정본 반영: 세 번들 순차 `load_bundle` 4.7초, 2,707필지·속성 2,707행, 경계 겹침 17필지는 변화 없음(자료명·해시만 다름). 재반영은 변화 없음. `build_projection`(가상 시드 5개 추가) 게시, `parcels.geojson` 2,707필지·속성 출처 9개, 스키마 통과, ZIP 339KB.
- 저장소에는 실제 자료·번들·PNU 를 넣지 않았다. 위 수치만 기록한다.

## 데이터 사전에 없어 정한 값

- `parcel_attributes` 열 구성(자료 그대로의 19개 값 + 출처·기준일·해시). 기준일 `as_of` 는 번들의 도형 기준일(다운로드 시점의 기준일로 사용자가 적는다). 속성 갱신 규칙(같거나 새로운 기준일이면 갱신).
- 용도지역 색 분류 8종(전용주거·일반주거·준주거·상업·공업·녹지·관리/농림/자연환경·기타)과 색. 표시용이며 규제 판단이 아니다.
- 폰 패널 항목 순서와 "미확인" 표기. 공시지가는 원/㎡ 와 기준 연월.

## 리뷰 반영 (PR #71, Codex 3건)

- P1 부분 자료 묶음: 번들에 든 자료 종류(`attrs_sources.kind`)의 필드 묶음만 갱신하고 없는 자료의 값·출처는 기존 행을 유지한다(`ATTR_GROUPS`). 이전에는 없는 필드를 null 로 덮어 공시지가·소유가 지워졌다.
- P2 속성 기준일: 파생본 `attrs.as_of`(스키마 추가)로 필지마다 실어 폰 패널이 "속성 기준일" 을 도형 기준일과 따로 보인다. 파생본을 다른 정본에 넣을 때도 이 값을 기준일로 쓴다.
- P2 면적 null: 토지특성 자료가 든 번들에서 값이 없으면 `parcels.registered_area_m2` 도 null + `not_collected` 로 되돌린다.

## 미확인 변수

- VWorld 자료의 이용조건·갱신 주기·다운로드 구역 상한은 배포처에서 사용자가 확인한다(작업 환경에서 접근 불가). `--license` 에 적는다.
- (J5-032 에서 정정) 이름 목록은 코드와 위치로 짝지으면 어긋난다는 것을 재실측으로 확인해, 코드·관계 짝과 이름 목록을 따로 두도록 바꿨다. 아래 문장은 J5-025 당시 기록이다.
- 잘린 지역지구 이름은 코드로만 남는다. 코드→이름 표(국토교통부 지역지구 코드)는 공식 자료를 확인한 뒤 별도 작업으로 넣는다.
- `lbl`(소유 구분명)이 코드 02·04·05 모두 "국유지" 로 표기된 행이 있었다. 자료의 표기 그대로 두고 코드를 함께 저장했다. 코드 의미는 공식 코드표 확인 항목이다.
- 폰에서 2,700필지 속성이 든 번들(약 4MB, 파생본 ZIP 339KB)의 읽기 시간·메모리는 실기기 확인 항목이다.

## 남은 인수조건·후속 작업

- 사용자(Mac): 실데이터 홈에서 `backup` → 구역별 `parcels convert` → `db parcels-load` 3회(마이그레이션 15 적용) → `project` → `project-copy` → 폰 설정의 PC 자료 파일로 넣고 필지 패널·용도지역 색 확인.
- 후속 후보: 지역지구 코드→이름 표, 공시지가 연도별 이력(기준일별 행), 건축물대장 자료 연결(별도 자료), 배경 타일(VWorld 키 확인 뒤 미리 설정 켜기).
- 자동 테스트·실측 통과는 자료 이용조건·법률 검증이 아니다.
