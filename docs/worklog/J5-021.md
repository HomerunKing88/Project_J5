# J5-021 외부 지도에서 보기 링크

기록일: 2026-09-27. 사용자가 토지이음 앱의 화면(연속지적도 위 필지 선택, 네이버 지도 배경)을 보여 주며 같은 방식의 배경 확인을 원했다. 배경 타일 연동은 온라인 전용·키 노출·약관 문제로 보류하고(ADR-15), 먼저 사용자가 누를 때만 좌표를 넘기는 외부 지도 링크를 넣었다. 다음 작업은 공공 도형 자료(도로·건물 윤곽)를 필지처럼 파일로 넣는 오프라인 배경 층이다.

## 결과

- `web/app/extmap.js`(새 파일): `EXTERNAL_MAPS`(Apple 지도·네이버 지도·카카오맵·Google 지도), `externalMapLinks([경도, 위도])`, `roundPoint`(소수 6자리, 범위 검사), `bboxCenter`, `LINK_ATTRS`(`target=_blank`, `rel=noopener noreferrer external`, `referrerpolicy=no-referrer`). 좌표와 고정 문구 "선택 위치" 만 담고 물건 이름·지번·PNU·기록은 넣지 않는다.
- `web/app/main.js`: 지도 선택 카드(`#map-selected-ext`)와 필지 패널(`#parcel-ext`, bbox 가운데 점)에 "다른 지도에서 보기" 링크를 그리고, 카드를 닫거나 좌표가 없으면 숨긴다. 앱 버전 0.2.1.
- `web/index.html`·`web/styles.css`: 링크 칩(`.ext-links`), 범례 설명에 전송 범위 문구. `web/sw.js`: 캐시 목록에 `extmap.js`, 캐시 이름 v0.2.1.
- `tests/test_web_static.py`: 외부 URL 금지 검사에서 `app/extmap.js` 만 예외로 두고, 그 파일의 https 호스트가 허용목록 4개와 같고 통신·이동·저장 API 와 이름·지번 필드가 없으며 main.js 가 호스트를 직접 쓰지 않는지 검사한다.
- 테스트: `tests/web/extmap.test.mjs`(5건), `app.e2e.test.mjs` 에 선택 카드 링크 4개의 href·속성·이름 미포함과 필지 패널 링크 확인.
- 문서: ADR-15, 공식 확인 자료 E08, 릴리스 계획 §10 J5-021 행, `web/README.md`, `tests/README.md`, 색인.

## 확인한 사실과 미검증

- Apple 지도 URL 형식(`ll`·`q`·`z`)은 공식 문서로 확인했다(E08, 2026-09-27).
- 네이버 지도(`map.naver.com/v5/?c=경도,위도,17,0,0,0,dh`), 카카오맵(`map.kakao.com/link/map/이름,위도,경도`), Google 지도(`google.com/maps/search/?api=1&query=위도,경도`)는 작업 컨테이너에서 각 공식 문서와 호스트 접근이 차단돼 확인하지 못했다. 링크 `title` 에 "형식 미검증" 을 남겼고 실기기 확인 항목이다. 형식이 틀려도 그 서비스의 기본 화면이 열릴 뿐 앱 데이터에는 영향이 없다.
- 새 창 열기·`noopener`·`no-referrer` 는 표준 HTML 속성이며, iOS Safari 에서 설치된 지도 앱으로 넘어가는지(유니버설 링크)는 실기기에서 확인한다.

## 테스트 명령과 결과 (2026-09-27, 컨테이너 Linux, Node 22, Python 3.12)

- `python -m pytest -q` → 전체 통과.
- `node --test tests/web/*.test.mjs` → 49 pass, 0 fail (단위 + e2e 2개).
- 헤드리스 Chromium 390×844 캡처 4장(선택 카드·필지 패널, 라이트·다크)으로 링크 칩 배치를 확인했다. 파일은 세션 임시 폴더에 있고 저장소에는 넣지 않았다.

## 미확인 변수

- iPhone 에서 링크 4개가 각각 앱 또는 웹으로 열리는지, 네이버·카카오·Google 링크 형식.
- 외부 서비스 약관은 링크로 여는 일반 사용 범위로 보았고, API 키·임베드는 쓰지 않는다.

## 남은 인수조건·후속 작업

- 실기기 확인 뒤 열리지 않는 링크의 형식을 고친다.
- 다음: 공공 도형 자료(도로명주소 기본도 등)를 조사 범위로 잘라 오프라인 배경 층으로 그리는 작업(변환기 + 지도 층). 그 뒤 조회 파생본을 폰이 읽어 필지·물건별 연도 타임라인을 보이는 작업.
