# J5-019 현장 앱 화면 정리

기록일: 2026-09-26. 첫 실사용(Mac 로컬 서버 `http://<Mac IP>:8000/` 로 폰 앱을 연 뒤)에서 확인된 필요다. 사용자 의견: 화면에 스타일이 없어 무엇을 하는 화면인지 알 수 없고, 지도가 보이지 않으며, 실제 사용자에게 필요 없는 내부 용어가 많이 노출된다. 릴리스 계획 §10 에 J5-019 로 추가했다.

## 결과

- `web/index.html` 을 다시 구성했다. 상단 고정 바(앱 이름·상태 요약) → "이 앱으로 하는 일"(3단계 안내) → 1단계 조사 설정(조사 이름이 저장돼 있으면 접힘, 요약 표시) → 2단계 물건 목록 불러오기 → 3단계 지도(물건이 없으면 안내를 지도 위에 겹쳐 표시, 필지 경계 파일은 접힌 절) → 목록에서 고르기(불러온 물건 전부, 지도에 없는 물건 포함) → 기록 폼 → 이 기기에 저장된 기록 → 내보내기 → 다른 기기로 옮길 때(접힘). 요소 ID 는 모두 유지했다(e2e·정적 검사가 ID 에 묶여 있다).
- 용어를 사용자 용어로 바꿨다: study_id → 조사 이름, synthetic/private_real → 연습용/실제, 시드 → 물건 목록(파일), 필지 번들 → 필지 경계 파일, 관측 기록 → 기록하기, 관측 상태 → "지난번과 비교해 어떤가요?", origin → 이 주소. 내부 용어는 힌트 문구와 PC 문서에만 둔다. 기록 목록의 이벤트 ID·해시 줄은 화면에서 뺐다(파일과 PC 에 있다).
- `web/styles.css` 를 새로 썼다. 색 토큰(라이트·다크, `prefers-color-scheme`), 시스템 글꼴 스택(외부 글꼴 없음: CSP `default-src 'self'`), 카드·단계 표시·44px 터치 목표·주 버튼, 지도 마커·필지·축척 색을 토큰으로. `[hidden]` 은 `display: none !important` 로 고정해 클래스의 `display` 에 밀리지 않게 했다(빈 필지 패널이 보이던 결함).
- `web/app/main.js`: 모드 표시 라벨(`MODE_LABEL`), 물건 목록 항목(이름·모드·기록하기·위치 요약), 설정 요약·접기, 지도 빈 상태 안내 토글, 기록 목록 배지, 상태 표시줄 순서, 파일 오류 문구. 버튼·입력 리스너를 첫 렌더 전에 붙여 첫 화면 직후의 탭이 무시되지 않게 했다(화면 촬영 스크립트에서 드러난 순서 문제).
- 리뷰 반영(PR #64, Codex 2건): 캐시한 앱 파일이 바뀌었으므로 앱 버전·서비스 워커 캐시 이름을 0.1.1 로 올렸다(HTTPS 에서 이미 연 브라우저가 새 화면을 받도록). 물건 목록을 지도 아래로 옮겨 완료 조건 "지도가 목록 위에 보임" 과 맞췄다(불러오기 버튼은 2단계에 그대로).
- 테스트: e2e 의 바뀐 문구 두 곳(`물건 목록 파일 오류`, `현재 목록에 없는 물건`)만 맞췄다. 정적 검사 7건, 단위·e2e 38건 통과. 헤드리스 Chromium 으로 폰 폭(390px) 빈 상태·채운 상태·다크, 데스크톱(900px) 화면을 한 번씩 확인했다.

## 정한 값

- 색: 바탕 `#f3f4f1`, 카드 `#ffffff`, 강조 `#1e6b5a`(파비콘 녹색 계열), 선택 `#d9822b`, 상태색 ok/warn/bad 별도. 다크는 같은 토큰을 재정의한다.
- 글꼴: `-apple-system, "Apple SD Gothic Neo", Pretendard, "Noto Sans KR", system-ui`. 본문 15px, 제목 1.05~1.15rem.
- 지도 높이 320px(600px 이상 폭에서 400px). 마커·필지·라벨 색은 CSS 토큰(`currentColor` 기반), 라벨 테두리는 `--surface-2`.
- 설정 절은 조사 이름이 저장돼 있으면 접힌다. 필지 경계 파일 절과 이전 준비 절은 기본 접힘.

## 공수

- 예상 2~3시간, 실제 약 1.5시간(화면 확인 포함).

## 미확인 변수·남은 인수조건

- iPhone Safari 실기기에서 다크 모드·터치 목표·접힘 동작·파일 선택 문구(브라우저 언어)를 확인한다.
- 문구·순서는 사용자가 써 본 뒤 의견을 반영한다. 내부 상태 문구(지도·필지·내보내기 안내)는 테스트와 묶여 있어 이번에는 바꾸지 않았다.
- `devtest.html` 은 같은 스타일 시트를 쓰지만 구성은 바꾸지 않았다.
