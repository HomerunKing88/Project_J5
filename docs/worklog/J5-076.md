# J5-076 단독·다가구·토지 실거래 응답 필드 확인

기록일: 2026-10-14. 사용자 지시: "J5-065 에서 가정한 단독·다가구·토지 실거래 API 필드 이름(totalFloorAr·houseType·dealArea·jimok)을 실제 응답으로 확인". J5-065 미확인 변수와 남은 인수조건의 첫 실제 응답 확인이다.

## 실행

- 환경: 클라우드 컨테이너(Linux, Python 3.11), 인증키는 환경변수 `DATA_GO_KR_SERVICE_KEY`, 네트워크 허용 `apis.data.go.kr`. `J5_DATA_HOME` 은 저장소 밖 임시 폴더. 원본 행·실행 기록·인증키는 커밋하지 않았다(임시 폴더의 모든 파일에 인증키 문자열이 없음을 확인).
- `python -m j5 collect rt-sample --kind sh --lawd-cd 11110 --months 2026-08` → complete, 13건(1페이지, 결과 코드 000, HTTP 200, 2회 시도·14.2초, 응답 6,551바이트). 명령 전체 14.9초.
- `python -m j5 collect rt-sample --kind land --lawd-cd 11110 --months 2026-08` → failed, HTTP 403, 포털 사유 `30 SERVICE_KEY_IS_NOT_REGISTERED_ERROR`(등록되지 않은 서비스키). 명령 전체 1.0초. 같은 키로 단독·다가구는 받았으므로 토지 매매 API 활용신청이 이 키에 없거나 승인 반영 전으로 본다. 응답 필드는 확인하지 못했다.

## 단독·다가구 요약(report, 2026-08 종로구 13건)

- 응답 필드(13건 모두 같은 목록): `buildYear`·`buyerGbn`·`cdealDay`·`cdealType`·`dealAmount`·`dealDay`·`dealMonth`·`dealYear`·`dealingGbn`·`estateAgentSggNm`·`houseType`·`jibun`·`plottageAr`·`sggCd`·`slerGbn`·`totalFloorAr`·`umdNm`.
- 가정과 대조
  - `totalFloorAr`(연면적): 있음, 13/13 채움(11.74~394.45).
  - `plottageAr`(대지): 있음, 13/13 채움.
  - `houseType`(주택유형): 있음, 13/13 채움, 값은 단독 11·다가구 2(코드의 `SH_HOUSE_TYPES` 와 같은 글자).
  - `shareDealingType`(지분 구분): 응답에 태그 자체가 없다. 상업·업무용처럼 빈 태그로 오지 않는다.
  - `landUse`(용도지역): 응답에 없다.
- 지번 `jibun`: 13/13 마스킹(`1**`·`3*`·`*` 등, 앞자리 숫자 뒤 `*`). 상업·업무용과 같은 모양이며 `*` 하나만 온 1건은 앞자리가 없다.
- 해제 `cdealType`·`cdealDay`: 태그는 있고 이 달은 모두 빈 값.
- 저장된 원본으로 정규화(`j5.db.transactions.normalize(..., "sh")`)를 돌려 본 결과(정본 반영 없음): 13건 모두 거래일·금액·연면적·대지·건축년도·주택유형(→ `building_use_raw`, 건물 구분 general)이 채워지고 사유(`missing_reasons_json`)는 비었다. null 은 응답에 없는 열(`building_type_raw`·`land_use_raw`·`floor_raw`)과 해제일, 앞자리 없는 지번 1건의 `jibun_prefix` 다.

## 판단

- 단독·다가구 필드 이름은 J5-065 가정과 같다. `j5/db/transactions.py` 정규화와 식별 필드는 고치지 않았다.
- 식별 필드의 `landUse`·`shareDealingType` 은 응답에 없어 늘 빈 값으로 해시에 들어간다. 해시 값은 응답마다 같게 나오므로 중복 판정에는 영향이 없고, 바꾸면 J5-065 시험의 기대값만 바뀐다. 정본에 단독·다가구 거래가 아직 없으므로 지금은 그대로 둔다.
- 단독·다가구 지분 거래는 응답으로 가릴 수 없다. 범위 기본값은 J5-065 대로 unclear 이며 검토에서 정한다.
- 토지(`dealArea`·`jimok`)는 여전히 가정이다.
