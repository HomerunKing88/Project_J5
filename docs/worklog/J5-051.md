# J5-051 폰 연도별 요약의 연도 상한

기록일: 2026-09-30. 폰 필지 이력의 연도별 요약(J5-047)은 최근 20개 연도만 보였다. 거래 수집 목표는 2006-01 부터이므로 2026 년까지 21개 연도가 되고, 가장 오래된 연도가 안내 없이 빠진다(J5-047 미확인 변수). PC `db parcels-years` 는 40개 연도까지 받는다.

## 결과

- `web/app/view.js`
  - `YEAR_SUMMARY_MAX = 40`: 폰 연도 상한을 PC `parcels-years` 의 `MAX_YEARS` 와 같게 했다.
  - `parcelYearSummaryInfo`: 같은 줄에 더해, 상한 때문에 보이지 않는 앞 연도를 `{from, to, count}` 로 돌려준다. 수는 자료(공시지가·거래·수집 현황)가 있는 연도만 센다. `parcelYearSummary` 는 줄만 돌려주며 전과 같다.
- `web/app/main.js`·`web/index.html`: 빠진 연도가 있으면 연도별 요약 아래에 "YYYY~YYYY년 중 자료가 있는 N개 연도는 여기 보이지 않습니다. PC 에서 `j5 db parcels-years` 로 봅니다." 를 보인다. 앱 0.2.19, 캐시 v0.2.19.
- 시험
  - `tests/web/view.test.mjs`: 2006~2026 의 21개 연도가 모두 보이고 빠진 연도 없음, 상한을 넘으면 자료가 있는 앞 연도만 세어 범위와 함께 알림, 빈 자료. 고치기 전 코드에서 실패함을 확인했다.
  - `tests/web/app.e2e.test.mjs`: 가상 파생본(2개 연도)에서는 빠진 연도 안내가 숨겨져 있음.
- 문서: 릴리스 계획 §10 J5-051, `web/README.md`, 색인(J5-050 #97).

## 데이터 사전에 없어 정한 값

- 빠진 연도 수는 자료가 있는 연도만 센다. 공시지가·거래·수집 현황이 모두 없는 해는 세지 않는다.

## 테스트 명령과 결과 (2026-09-30, 컨테이너 Linux, Node 22, Python 3.11)

- `node --test --test-timeout=180000 "tests/web/*.test.mjs"` → 84 pass (새 시험 1건 포함).
- `python -m pytest -W error::UserWarning` → 436 passed (PC 변경 없음).
