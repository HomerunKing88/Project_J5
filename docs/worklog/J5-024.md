# J5-024 앱 안 배경 지도 타일

기록일: 2026-09-27. 사용자가 J5-021 의 외부 지도 링크를 써 본 뒤 "매번 눌러서 지도로 넘어가는 건 의미가 없다, 앱 안에서 모두 보고 싶다, 필요하면 지도를 내려받거나 API 를 연결하라" 고 결정했다. ADR-15 의 보류를 풀고 ADR-18 로 앱 안 배경 타일을 채택했다. 외부 링크는 보조로 남긴다.

## 결과

- `web/app/tiles.js`(새): 제공자 미리 설정(VWorld 기본·항공·하이브리드, 직접 입력), 설정 해석(`resolveTileConfig`: 키 URL 인코딩, 허용 호스트·같은 출처·경로 탈출 검사), 키 가리기, 타일 URL, 축척→확대 단계(고해상도 +1), 화면을 덮는 타일 목록·위치, 미리 받기 계획(bbox·단계 14~18·상한 3,000), bbox 여유.
- `web/app/map.js`: 맨 아래 `layer-tiles` 층. `setTiles(cfg)` 로 켜고 끄며 `render()` 마다 필요한 타일 `<image>` 만 남기고 위치·크기를 갱신한다. 실패한 타일은 숨기고 `onTileStatus` 로 알린다. 오른쪽 아래 출처 표시. 타일이 켜지면 도로·건물 배경 층은 반투명.
- `web/sw.js`: 허용 호스트(`api.vworld.kr`) 또는 같은 출처 `/tiles/` 요청을 캐시 우선으로 처리하고 `j5-tiles-v1`(앱 캐시와 별도, 상한 6,000장)에 저장한다. 교차 출처는 `no-cors` 로 받아 불투명 응답을 그대로 저장한다.
- `web/index.html`·`main.js`·`styles.css`: 설정에 "배경 지도 (온라인 타일)" 블록(제공자, 인증키(password, 기기에만 저장), 직접 입력 템플릿, 저장, 저장된 타일 수, 이 범위 미리 받기, 지우기, 약관 안내). CSP `img-src` 에 `https://api.vworld.kr` 만 추가. 지도 안내에 "배경 타일 켜짐 / N장 못 받음(오프라인·키 확인)". 미리 받기는 대상·필지 범위(여유 300 m)를 `Image` 로 순서대로 받아(동시 4) 서비스 워커가 저장하게 한다. 앱 0.2.4, SW 캐시 v0.2.4.
- 정적 검사(`tests/test_web_static.py`): index.html 은 CSP 의 타일 호스트만, `tiles.js` 는 스킴 문자열만(완성 URL 없음)·통신 API 없음, `tiles.js`·`sw.js`·CSP 의 허용 호스트 목록이 같아야 한다. 서비스 워커 `fetch` 는 `e.request` 만.
- 테스트: `tests/web/tiles.test.mjs`(4건), `app.e2e.test.mjs` 배경 타일 절(허용 밖 호스트 거절 → 같은 출처 가짜 타일 켜기 → 타일 image·맨 아래 층·출처 표시·서버 요청 → 확대 시 추가 요청 → 미리 받기 → 캐시 재사용(서버 요청 불변) → 끄기·다시 켜기) 와 오프라인 단계에서 저장된 타일 표시·타일 캐시 잔존 확인. `tests/web/cdp.mjs` 의 `serve` 에 추가 경로 핸들러.
- 문서: ADR-18, ADR-15 경계 문구, 릴리스 계획 §10 J5-024 행, `web/README.md`, `tests/README.md`, 색인(J5-023 PR 번호).

## 확인한 사실과 미검증

- VWorld 타일 API 의 URL 형식(`/req/wmts/1.0.0/{키}/{층}/{z}/{y}/{x}`)·확대 범위·약관은 작업 환경에서 공식 문서와 호스트 접근이 모두 차단돼 확인하지 못했다. 미리 설정은 `verified: null` 로 두고 화면 안내에 "형식 미확인" 을 붙였다. 형식이 다르면 제공자 문서의 형식을 "직접 입력" 에 넣으면 된다(허용 호스트 안이면 통과).
- 같은 출처 타일(`./tiles/{z}/{x}/{y}.png`)로 렌더·캐시·오프라인을 검증했다. 교차 출처 불투명 응답의 캐시 저장은 표준 동작이지만 실기기에서 확인한다.

## 테스트 명령과 결과 (2026-09-27, 컨테이너 Linux, Node 22, Python 3.12)

- `python -m pytest -q` → 전체 통과.
- `node --test tests/web/*.test.mjs` → 69 pass, 0 fail (단위 + e2e 2개).

## 실제 작업 시간

약 2시간 (설계·검사 규칙 0.4, 타일 계산·지도 층·서비스 워커 0.6, 설정 화면·미리 받기 0.5, 테스트·기록 0.5).

## 미확인 변수

- VWorld 키 발급·서비스 URL 등록(폰이 여는 주소를 등록해야 함), 약관의 캐시·오프라인 사용 범위와 호출 한도.
- iPhone Safari 의 서비스 워커 캐시 용량(수천 장 타일)과 홈 화면 앱 모드에서의 캐시 유지.
- 고해상도(dpr 2)에서 한 단계 위 타일을 받으므로 요청 수가 4배다. 통신량이 부담이면 `tileZoom` 의 dpr 보정을 끈다.

## 남은 인수조건·후속 작업

- 사용자: VWorld 에서 키를 받아 설정에 넣고 지도가 보이는지, "이 범위 미리 받기" 뒤 비행기 모드에서 보이는지 확인한다. 안 보이면 안내 문구의 오류와 캡처를 보내 준다.
- 후속 후보: 용도지역 색(토지이용규제 공간정보)을 필지처럼 파일로 넣는 층, 타일 캐시 용량 표시, 현재 위치 표시(위치 권한은 사용자 승인).
- 자동 테스트 통과는 실제 제공자·실기기 검증이 아니다.
