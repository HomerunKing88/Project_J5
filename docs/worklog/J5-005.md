# J5-005 최소 지도·목록

기록일: 2026-09-22.

## 결과

- `web/app/map.js`: 자체 SVG 점 지도(ADR-12). Web Mercator 투영(`mercator`/`unmercator`), 전체 보기(`fitView`), 앵커 고정 확대(`zoomAt`), 이동(`pan`), 축척 막대(`scaleBar`), `createMap(svg, { onSelect })`. `location_point` 있는 물건만 마커로 그리고, data_mode 로 마커 모양을 구분한다(synthetic 점선 빈 원, private_real 채운 원). 포인터 이벤트로 드래그·두 손가락 핀치·탭, 휠 확대, 버튼 `+`·`−`·`전체 보기`. 배경 타일·외부 통신 없음.
- `web/index.html`·`styles.css`: 시드 절 아래 지도 절(정적 `<svg>`, 버튼, 범례, 안내). CSP·정적 보안 규칙 변경 없음. 스타일은 `styles.css` 에만 둔다(SVG 인라인 `style` 은 CSP 위반).
- `web/app/main.js`: `initMap`(실패 시 `지도 표시 불가: <이유>. 목록에서 선택한다` 안내만), `mapCall`(지도 런타임 실패도 목록 우선), 시드 로드 후 지도 갱신·안내(`위치점 n개 표시 (가상 a · 실제 b) · 위치점 없는 물건 k개 (목록에서 선택)`), 마커 탭 → `startObservation`, 관측 저장·취소 시 선택 해제. `sw.js` 캐시 목록에 `map.js`.
- 테스트: `tests/web/map.test.mjs`(투영 기준값·역투영·맞춤·점 하나·극소 범위·빈 배열·앵커 고정·클램프·m/px·축척 막대·라벨 절단), e2e 확장(마커 4개·주소만 있는 물건 1개 안내, 실제 마우스로 마커 탭 → 관측 대상 선택·강조, 확대 후 좌표 변화·동서 순서 유지, 전체 보기 복귀, 시드 교체 시 마커 수, 주소만 있는 시드 안내, `createElementNS` 스텁으로 지도 실패 → 안내·목록 5개·기록 유지·목록으로 선택·콘솔 오류 0, 오프라인 재접속에 `map.js` 캐시 포함). `test_no_vendor_yet` 설명 갱신.
- 문서: ADR-12, ADR-01 참조 문구, `web/README.md`.

## 조사 결과 (렌더러 선택)

- MapLibre `latest` 6.11.0(2026-09-22 공개, BSD-3): `dist/maplibre-gl.mjs` 587KB + `-shared.mjs` 515KB + `-worker.mjs` 19KB + CSS 83KB. UMD `maplibre-gl.js` 는 5.24.0 이 마지막. 번들에 `XMLHttpRequest`, `innerHTML`(Popup.setHTML), 워커 `globalThis.eval`(클래식 스크립트 로드 경로), blob 워커, `import.meta.url` 이 있다. 텔레메트리 엔드포인트는 없다.
- 헤드리스 Chromium 141 은 `--disable-gpu` 에서 WebGL 없음, `--use-angle=swiftshader --enable-unsafe-swiftshader` 로 WebGL 2 가 뜬다. MapLibre 를 넣더라도 e2e 는 가능하다.
- 사용자 결정: 자체 SVG 점 지도, 이번 작업은 타일 없음.

## 데이터 사전에 없어 정한 값

- 축척 범위 `MIN_SCALE = 256`(z0) ~ `MAX_SCALE = 256·2^22`. 전체 보기 확대 상한 `FIT_MAX_SCALE = 256·2^17`(북위 37.6° 에서 약 0.95 m/px). 전체 보기 여백 40px.
- 마커: 점 반지름 7px(선택 10px), 터치 영역 반지름 18px, 라벨 12 코드 포인트 초과 시 `…` 절단(전체 라벨은 `<title>` 과 목록에), 탭 판정 이동 6px 미만.
- 축척 막대 눈금 1·2·5·10·20·50·100·200·500·1000·2000·5000 m, 최대 120px.
- 지도 실패 문구 `지도 표시 불가: <이유>. 목록에서 선택한다`. 지도 실패는 콘솔 오류로 내지 않는다.

## 공수

- 예상 6~8시간. 실제(세션 기준) 약 1.5시간(조사 포함) + 리뷰 반영 약 0.5시간. 재작업: 단위 테스트 기대값 조정(시드 범위가 확대 상한에 걸림, 최대 확대에서 5m 막대가 120px 초과 → 1·2m 눈금 추가), e2e 마커 좌표를 svg 기준으로 바꿈(버튼 클릭 시 스크롤로 viewport 좌표가 변함).
- 리뷰 반영(PR #34): `map.js` 를 정적 import 에서 `initMap` 안의 동적 `import()` 로 바꿈(모듈 로드 실패가 목록·기록·내보내기를 막지 않도록). e2e 첫 접속에서 `Network.setBlockedURLs` 로 `map.js` 를 막아 이 경로를 확인한다.
- CI: 커밋 `0e59df6` 의 web 작업이 러너의 Chrome 기동 대기 10초를 넘겨 `Chromium CDP 연결 실패` 로 끝났고, 기동 실패 시 정적 서버를 닫지 않아 파일 타임아웃(180초)까지 매달렸다. 기동 대기를 60초로 늘리고 기동을 `try` 안으로 옮겨 `finally` 가 서버를 닫게 했다.

## 미확인 변수·남은 인수조건

- iPhone Safari 실기기: 두 손가락 핀치·`setPointerCapture`·`touch-action: none`·`gesturestart` 동작, 다크 모드 `Canvas` 색상. 사용자가 실기기 시험(J5-004·006·007)을 미뤄 두었으므로 함께 확인한다.
- 라벨 겹침은 처리하지 않는다(점이 가까우면 라벨이 포개진다). 실제 물건 배치를 본 뒤 필요하면 별도 작업.
- `AGENTS.md` 구성 절의 "고정 버전 MapLibre" 문구는 처음에 범위 밖으로 두었으나, 리뷰에서 ADR-12 와의 충돌 지적을 받아 사용자 결정으로 이 PR 에서 한 구절만 ADR-12 참조로 갱신했다.
- 완료 조건 "가상/실제 구분"은 마커 모양·범례·안내 문구로, "지도 실패 시 목록"은 e2e 실패 경로로 확인했다. 실제 타일·실기기 검증은 하지 않았다.
