# J5-044 지번 대조에 시군구 코드

기록일: 2026-09-28. 거래와 필지는 법정동 이름과 지번으로 대조했다. ADR-23 부터 정본에 여러 지역을 넣으므로, 이름이 같은 다른 시군구의 법정동(예: 여러 구에 같은 이름의 동이 있다) 거래가 이 필지에 붙을 수 있었다. J5-043 에서는 시군구 코드가 다르면 표시만 하고 후속으로 남겼다.

## 결과

- 규칙: 거래의 시군구 코드(`lawd_cd`, 수집 요청의 시군구)와 필지 PNU 앞 5자리가 다르면 법정동 이름·지번이 같아도 대조하지 않는다. 세 곳에 같게 넣었다.
  - PC 연결 후보 CSV(`j5/db/txlinks.py` `candidates`): `linked_parcels` 에 `sgg_code` 를 더하고 시군구가 다르면 후보가 아니다.
  - PC 필지 이력(`j5/db/parcel_timeline.py`): 다른 시군구의 같은 이름 법정동 거래는 목록에 넣지 않고 `other_sgg` 로 센다(취소 확정은 세지 않음). 글에 "다른 시군구의 같은 이름 법정동 n건 제외". JSON 키는 `transactions_sgg_differs`(J5-043) 대신 `transactions_other_sgg`.
  - 폰 필지 이력(`web/app/view.js` `jibunMatch`): 거래 `lawd_cd` 와 필지 `emd_code` 앞 5자리가 모두 있고 다르면 null. 한쪽이 없는 파일은 이전처럼 이름으로만 본다. 앱 0.2.16, 캐시 v0.2.16.
- 사람이 확정 연결(confirmed)한 거래는 시군구가 달라도 필지 이력에 "연결 물건의 거래" 로 들고 줄에 "시군구 코드 다름(거래 …)" 을 적는다. 확정은 근거를 본 사람의 결정이므로 규칙으로 가리지 않는다.
- 가상자료: 필지 대조를 시험하는 가상 거래(`tests/test_j5_014b2_txlinks.py`, `tests/fixtures/make_view.py`)의 시군구를 가상 필지와 같은 99999 로 바꿨다. 이전에는 거래가 종로구 11110, 필지가 99999 여서 시군구를 대조하면 모두 빠졌다. 필지와 대조하지 않는 수집·반영 시험은 11110 그대로다.
- 시험
  - `tests/test_j5_044_sgg_match.py` 2건: 같은 이름 "가상동" 을 가진 다른 시군구(11110) 거래는 필지 이력에 들지 않고 수만(취소 확정 제외), 연결 후보도 없음. 다른 시군구 거래를 사람이 확정 연결하면 연결 물건의 거래로 보이고 표시됨. 고치기 전 코드에서 둘 다 실패함을 확인했다.
  - `tests/web/view.test.mjs`: 시군구가 같으면 exact, 다르면 null(번지대 포함), 필지에 법정동 코드가 없으면 이름으로만. 고치기 전 코드에서 실패함을 확인했다.
  - J5-043 시험의 가상 거래 시군구 단언을 새 가상자료에 맞췄다.
- 문서: 릴리스 계획 §10 J5-044, `j5/README.md`(필지 이력·rt-candidates), `web/README.md`, `tests/README.md`, 색인(J5-043 #90).

## 데이터 사전에 없어 정한 값

- 시군구 코드는 거래의 `lawd_cd` 를 쓴다. 제공자 행의 `sggCd` 는 `lawd_cd` 와 같다고 보고 따로 대조하지 않는다(수집은 시군구 단위로 요청한다).
- 폰은 필지의 `emd_code` 가 없는 파일(외부 도구로 만든 필지 파일 등)에서 이름으로만 대조한다. 파생본의 필지·거래 파일에는 두 값이 항상 있다.

## 테스트 명령과 결과 (2026-09-28, 컨테이너 Linux, Node 22, Python 3.11)

- `python -m pytest -W error::UserWarning` → 422 passed (새 시험 2건 포함, 44초).
- `node --test --test-timeout=180000 "tests/web/*.test.mjs"` → 82 pass.

## 실제 작업 시간

약 0.6시간 (조사 0.1, 구현 0.15, 가상자료·시험 0.2, 문서 0.15).

## 미확인 변수

- 실데이터 정본에 이름이 같은 다른 시군구 법정동이 함께 들어갈지는 사용자가 넣는 지역에 달렸다.
- 실제 응답의 `sggCd` 가 요청 시군구와 늘 같은지는 확인하지 않았다. 이 규칙은 `lawd_cd` 만 본다.

## 남은 인수조건·후속 작업

- 사용자(PC): 여러 시군구를 넣은 뒤 물건 필지로 `j5 db parcels-history <PNU>` 를 돌려 "다른 시군구" 제외 수를 본다. 연결 후보는 `rt-candidates --lawd-cd <시군구>` 로 다시 만든다.
- 사용자(폰): `project` → `project-copy` 뒤 PC 자료 파일을 다시 불러온다(앱 0.2.16).

각 명령의 세부는 `j5/README.md`, 폰 앱은 `web/README.md`.
