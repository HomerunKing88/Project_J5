# J5-030 공시지가 추이: 필지 패널의 연도별 표

기록일: 2026-09-27. J5-026 으로 정본에 기준일별 속성 스냅샷이 쌓이고 파생본에 변화 항목(`attrs_history`)이 실리지만, 폰에서는 항목이 이력 목록에 흩어져 있어 공시지가의 흐름을 한눈에 보기 어려웠다. 사용자의 목표("필지마다 정보와 거래정보를 연도별로 쌓아나가기")에 맞춰 이미 있는 자료로 추이 표를 만들었다. 외부 자료·새 스키마는 없다. 가상자료만 썼다.

## 결과

- 폰(`web/app/parcels.js`): `priceTrend(attrs, attrs_history)` 가 현재 속성에서 토지특성 변화 항목을 기준일 역순으로 짚어 각 기준일의 공시지가·기준연월을 되살린다. 변화 항목이 이전 값과 새 값을 함께 담으므로 되살린 값은 정확하다. 값이 바뀐 지점만 남기고(같은 값·같은 기준연월은 하나로), 직전 대비 증감률, 같은 기준연월에서 값이 바뀐 경우(정정 등) 표시, 파생본 이력 상한(200)으로 앞부분이 잘리면 가장 앞 변화의 이전 값을 "이전 자료 (기준일 모름)" 으로 둔다. `priceTrendRow` 가 화면 글.
- 폰(`main.js`·`index.html`·`styles.css`): 필지 패널의 속성 목록 아래 "공시지가 추이" 표(점이 둘 이상일 때만)와 안내 문구(자료 값 그대로, 시세·가치 판단 아님). 앱 0.2.9, SW 캐시 v0.2.9.
- PC(`j5/db/parcels.py`): `price_series(snapshots)` 가 같은 규칙으로 정본 스냅샷에서 추이를 만들고, `attribute_history` 결과에 `price_series`, `parcels-history` 글에 "공시지가 추이" 절(점이 둘 이상일 때).
- 테스트: `tests/test_j5_030_price_trend.py`(4건: 스냅샷 추이, 규칙, CLI 글·JSON, 파생본을 폰 함수로 되살린 결과와 정본 추이의 Node 대조), `tests/web/parcels.test.mjs` 3건, `app.e2e.test.mjs` 필지 1 의 추이 두 줄.
- 문서: 릴리스 계획 §10 J5-030, `j5/README.md`·`web/README.md`·`tests/README.md`, 색인(J5-029 PR #75).

## 데이터 사전에 없어 정한 값

- 추이의 점은 "공시지가 또는 기준연월이 바뀐 토지특성 기준일" 이다. 값이 같은 새 기준일은 점을 늘리지 않는다(정본 스냅샷은 남는다).
- 증감률은 바로 앞 점 대비이며 앞 점이 0 이거나 없으면 표시하지 않는다. 소수 한 자리.
- 같은 기준연월에서 값이 바뀌면 "같은 기준연월의 값이 바뀜 (정정 여부 확인)" 으로 적는다. 판단하지 않는다.
- 폰 표는 점이 둘 이상일 때만 보인다. 하나면 속성 목록의 공시지가가 전부다.

## 리뷰 반영 (PR #76 머지 뒤 Codex 1건, 후속 PR)

- P2 잘린 이력의 이전 값: 파생본 이력 상한(200)으로 앞부분이 잘렸는지를 "가장 앞 항목" 이 아니라 "남은 토지특성 항목에 '처음 확인' 이 없음" 으로 판정하고, 가격을 바꾼 항목이 하나라도 남아 있으면 그 가장 이른 가격 변화의 이전 값을 "이전 자료 (기준일 모름)" 으로 둔다. 이전에는 가장 앞에 남은 항목이 가격과 무관하면(이용상황만 바뀜 등) 이 값을 버려 추이 표가 사라질 수 있었다. 잘렸고 가격 변화가 하나도 남지 않았으면 현재 값 하나로 둔다. `tests/web/parcels.test.mjs` 에 두 경우를 더했다. 앱 0.2.10, SW 캐시 v0.2.10.


약 0.8시간 (설계 0.15, 폰 0.25, PC 0.1, 시험 0.2, 문서 0.1).

## 미확인 변수

- 실제 VWorld 토지특성 자료를 해마다 받아 쌓았을 때 기준연월 표기(연도만/연월)와 정정 빈도는 실측 항목이다. 지금 정본에는 기준일 하나(2026-09-05)만 있다.
- 공시지가는 공시 기준이며 시세·거래가격과 다르다. 거래 이력(J5-023)과 한 화면에서 비교하는 기능은 후속 후보다.

## 남은 인수조건·후속 작업

- 사용자(Mac): 이후 해마다(또는 공시 뒤) VWorld 토지특성 자료를 같은 구역으로 받아 `parcels convert` → `db parcels-load` 로 쌓고, `db parcels-history <PNU>` 와 폰 필지 패널에서 추이를 확인한다.
- 후속 후보: 추이 옆에 같은 필지의 실거래 연도별 요약, 관찰목록 물건만의 공시지가 변화 요약.
- 가상자료·브라우저 통과는 실제 자료·기기 검증이 아니다.
