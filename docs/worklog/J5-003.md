# J5-003 관측·ZIP·assets.seed.json 스키마, 가상 fixture

기록일: 2026-09-22. 브랜치 `claude/dazzling-gauss-2w71s7`.

## 결과

- `schemas/` 3종 (package_schema 1.0.0), `tests/fixtures/` 시드 1개·패키지 9종, `tests/test_j5_003_schemas.py`.
- 검증 의존성 jsonschema 4.23.0 고정 (ADR-01: 해당 단계에서 고정).

## 데이터 사전에 없어 정한 값 (계약 확정 시 사전에 반영 필요)

- `observed_at_precision` (`datetime`/`date`): "날짜만 알려졌으면 날짜 정밀도를 저장"을 필드로 표현했다.
- `payload.change_status` 값: `change_observed / no_change / hard_to_confirm`. 사진 태그 영문 키 7종.
- 선택 필드(`route_version_id`, `frame_version_id`, `corrects_event_id`)는 생략 대신 `null` 명시. 임의 필드 차단을 위해 additionalProperties=false.
- attachment_refs에 `bytes`·`mime` 포함. HEIC는 mime·확장자 모두에서 거절.

## 공수

- 예상: 4~6시간. 실제(세션 기준): 약 1시간. 실제 기기·ZIP 처리는 포함하지 않았다.

## 미확인 변수

- 실제 폰이 내는 JPEG/WebP 바이트·크기 (J5-004에서 확인). 스키마 통과는 기기 검증이 아니다.
- 이벤트 바이트 고정 방식이 IndexedDB 저장(J5-006)에서 어떻게 구현될지.

## 남은 인수조건

- 없음(J5-003 범위). 중복·충돌·누락 처리의 동작 검증은 J5-008·010에서 한다.
