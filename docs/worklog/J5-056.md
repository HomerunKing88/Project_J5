# J5-056 남은 화면 글 정리

기록일: 2026-10-02. J5-054 에서 현장·기록 화면과 기록하기의 글을 사용자 말로 바꿨지만, 설정의 자료 상태 줄과 필지 카드 안의 몇 곳은 예전 글이었다. 가운뎃점으로 이은 긴 줄에 `synthetic`·`file:`·`bundled_synthetic` 같은 내부 값이 그대로 보였고, 필지 카드의 대상 근거는 "정본 연결"·"위치점 포함 (연결 미확정)" 이었다.

## 결과

- `web/app/main.js`
  - 필지 상태(`parcelsNote`): 문장 단위로. "필지 6개 (연습용 자료). 자료 이름, 도형 기준일, 좌표계, 이용허락. 토지 자료가 든 필지 n개 (출처). 정본 vN. 파일 X, 오늘 22:05 가져옴." PC 가 적은 폰 범위 경고는 글 그대로 두고, 그 밖의 변환 경고 수는 "PC 의 변환 기록에서 봅니다" 로 안내한다. PC 에서 이은 대상이 대상 목록 교체로 보이지 않을 때의 안내도 다시 썼다.
  - 건물·도로 윤곽 상태(`basemapNote`)와 대상 목록 상태(`renderSeedStatus`)도 같은 문장 형식.
  - 자료 종류는 `synthetic`·`private_real` 대신 연습용 자료·실제 자료, 가져온 자리는 `bundled_synthetic`·`file:`·`view:` 대신 앱에 든 연습용 파일·파일·PC 자료 파일 (`DATA_MODE_TEXT`, `sourceText`).
  - 좌표계(EPSG)·이용허락·정본 버전은 자료를 확인할 때 필요하므로 남긴다.
- `web/app/parcels.js`
  - 필지 카드의 대상 근거 `BASIS_LABEL`: PC 에서 이은 대상은 "PC 연결", 위치만 이 필지 안에 있는 대상은 "위치로 찾음 (연결 전)". 근거 판정(`parcelAssets`)은 그대로다.
  - 속성 줄 "속성 기준일 X (토지 자료 기준, 도형 기준일과 다를 수 있음)" → "자료 기준일 X". 도형 기준일과 다를 수 있다는 설명은 "이 정보의 출처" 도움말로 옮겼다.
- 값·판정·저장 형식은 바뀌지 않는다. 앱 0.2.23 (`APP_VERSION`, `sw.js` 캐시, e2e 3곳).
- 시험: `tests/web/parcels.test.mjs`(근거 이름, 자료 기준일), `tests/web/app.e2e.test.mjs`(필지·건물 윤곽·대상 목록 상태 글, 근거 배지, 속성 줄). 단위 시험은 고치기 전 코드에서 실패함을 확인했다.

## 미확인 변수

- 폰 범위 경고("폰 범위: 정본 필지 n개 중 … 물건이 연결된 필지 m개만 실었다")는 PC(`j5 db project`)가 만든 글이라 이번에 바꾸지 않았다. PC 출력 글을 바꾸면 PC 시험과 문서가 함께 바뀌므로 필요하면 따로 다룬다.
- 실제 VWorld 자료 이름·이용허락 글이 길 때 설정 화면에서 읽기 편한지는 실제 자료로 확인한다.
