# J5-016 규제·개발안·자금 (R5)

기록일: 2026-09-25. 첫 조각 **A**: 계산기 세 종류(용적률 기준 여유면적, 매입 전체 필요자기자본, 사업기간 최대 필요자기자본)와 입력 계약. 완료 조건 "면적·총액/순액·최대 현금 테스트"(릴리스 계획 §10)를 데이터 사전 §9~§10 의 가상 검증 사례로 재현한다.

## A. 결과

- `schemas/calc_inputs.schema.json`(`kind: far / equity / cash`): 면적·금액은 값과 근거를 함께 두고, 미확인은 `null` 과 사유다. 0 으로 채우지 않는다.
- `j5 calc far <입력.json>`: A(법정 산정 대지면적)·F(적용 용적률)·C(용적률 산정용 연면적)로 검토면적·여유면적·소진율. A 는 직접 입력 또는 공부면적 − 확인된 법정 제외면적(`statutory_basis: registered_minus_excluded`). 어느 입력이든 미확인이면 결과 null, 분모 0 은 오류, 음수 여유면적은 그대로 표시. 배치 검토영역은 기록만 하고 A 를 대신하지 않는다. 분모 제외 여부 `unknown` 인 제약이 있거나 규제 버전이 없으면 A·F 를 확정할 수 없어 결과를 내지 않는다. 총연면적 < 산정용 연면적이면 오류. 규제 버전·면적 시점·계산식 버전을 결과에 남긴다.
- `j5 calc equity <입력.json>`: 가격 기준 정규화(총액 / 보증금 차감 후 + 확인된 차감액 / 잔금·미확인은 P 미확정) 뒤 P − L − D + T + B + V + R + E. 총액 입력에 차감액을 함께 주면 거절(이미 뺀 값에 D 를 다시 빼는 입력 금지). 보증금 공제가 금융기관 순대출 한도에 이미 들어 있으면 D 를 다시 차감하지 않되 반환 의무는 그대로 표시. 가격·다른 항목에 포함된 비용은 0. 기지급 계약금·중도금은 빼지 않고 "현재 시점 추가 잔금 현금" 으로 따로 보인다. 미확인 항목이 있으면 알려진 항목 합계만.
- `j5 calc cash <입력.json>`: 시점별 CF_t 를 합쳐 누적 최저를 찾고 max(0, −최저) + 별도 예비현금. 예비현금이 CF 에 있으면 더하지 않는다(둘 다 주면 거절). 소유자 자기자본 투입(`owner_equity`)은 거절. 시점은 기간 번호 또는 날짜(혼용 금지). 미확인 금액·미확인 예비현금이면 결과 null.
- 종료 코드: 계산 완료 0, 미확정(미확인 입력·오류) 1, 입력 거절 3. 결과 JSON 에 `calculation_version`(1.0.0)·계산식·미확인 목록·주의·경고문을 넣는다.
- 가상 검증(`tests/fixtures/calc/`): 대지 100㎡·F 600%·C 240㎡ → 검토 600·여유 360(배치 검토영역 60 은 무시), 제외 10㎡ 확인 → A 90·검토 540·여유 300. 총액 40억·L 24억·D 1억·기타 2억 → 17억, 순액 39억 + 차감 1억 → P 40억 복원 → 17억, 기준 미확인 → 미출력. 누적 −17·−20·−18억 + 예비 1억 → 21억. 테스트 `tests/test_j5_016a_calc.py` 6건.

## 데이터 사전에 없어 정한 값

- 결과 값은 면적 소수 3자리, 소진율 소수 6자리로 반올림한 뒤 담고, 금액은 원 단위 정수 그대로다.
- `included_in_price` / `included_in` 이 참인 비용은 0 으로 두고 주의에 적는다. 값이 함께 있어도 더하지 않는다.
- 총액 입력에 `deposit_already_deducted_krw` 가 0 이 아닌 값으로 오면 거절한다(모순 입력). `null` 이나 0 은 허용.
- 현금흐름의 시점은 정수 기간 번호 또는 `YYYY-MM-DD` 며 문자열 정렬로 시점 순서를 정한다. 같은 시점의 여러 항목은 합한다.
- 미확정 결과의 종료 코드 1 은 "실패" 가 아니라 "완성값 아님" 이다. 출력에 알려진 항목 합계를 남긴다.
- 입력 계약: 확인된 금액·면적에는 근거(`basis`)가, 미확인(`null`)에는 사유(`reason`)가 필수다(리뷰 반영). 현금흐름의 날짜 시점은 `YYYY-MM-DD` 만 받는다.
- 정본 저장(개발안·규제 버전·검토안 기록)은 이 조각에 없다. B 이후.

## 공수

- 예상(J5-016 전체): 릴리스 계획 R5 예산 범위. A 실제 약 1.5시간.

## 미확인 변수·남은 인수조건

- 실제 물건의 법정 산정 대지·제외면적·적용 용적률은 법령·지구단위계획·전문가 검토로 확인해야 하며 계산기는 확인된 값을 받을 뿐이다(ADR E03). 취득세율·거래비용은 세무·법무 확인 전 가정이다.
- B: 규제 버전·개발안(현상 유지·리모델링·철거신축·공동매입)·건축사 검토안을 정본 기록으로 두고 후보별 현금표·CSV 내보내기. 공사기간 공실, 부가세·비용 중복, 감정가 차이 시험.
