# J5-004 기기 파일·사진 시험

기록일: 2026-09-22 (페이지 작성). 실기기 결과는 아래 표를 사용자가 채운다. 채우기 전에는 완료가 아니다.

## 페이지

`web/devtest.html`. 아무것도 전송하지 않는다. 결과 JSON을 저장하거나 복사해 이 문서에 옮긴다.

## 절차 (iPhone + Safari)

1. PC에서 `python -m http.server 8000 --directory web` 실행, 폰에서 `http://<PC IP>:8000/devtest.html` 접속. (HTTPS 경로가 있으면 그쪽에서도 한 번 더.)
2. 1절 환경 표를 읽는다. 보안 컨텍스트·crypto.subtle·IndexedDB 왕복·저장 용량 값을 기록한다.
3. 2절에서 **사진첩 선택**으로 최근 촬영 사진 1장(기본 설정이면 HEIC일 가능성), 스크린샷 1장(PNG), 큰 사진 1장을 고른다. 각 항목의 `보고된 type`, `매직바이트 판정`, 크기, 읽기·해시 ms를 기록한다.
4. 2절에서 **카메라 촬영**으로 1장 찍는다. 형식과 크기를 기록한다.
5. "이 사진을 그대로 저장"을 눌러 이진 파일 저장이 어디로 가는지(공유 시트 → 파일 앱 등) 기록한다.
6. 3절 "결과 JSON 저장"을 누르고 '파일' 앱에서 열어 확인한다. 3절 목록에서 그 저장 항목(과 5번의 사진 저장 항목)을 체크한 뒤 "결과 JSON 저장"을 한 번 더 누른다. 마지막 JSON이 확인 상태까지 담은 최종 결과이며 이것을 PC로 옮긴다(AirDrop·케이블·iCloud 등 실제 쓴 방법을 기록).
7. 비행기 모드로 페이지를 다시 연다. 열리는지(캐시 없음이므로 안 열리는 것이 정상)와 `온라인` 값을 기록한다.

## 이 결과로 정할 것

- HEIC 처리: iPhone이 선택 시 JPEG로 바꿔 주는지에 따라 J5-006의 안내 문구와 J5-007의 거절 경로를 확정한다.
- §3.3 한도(압축 100MB·해제 250MB·사진 20MB)의 현실성. 큰 사진의 실제 바이트와 해시 시간으로 조정한다.
- 저장 위치·전송 방법이 `내보냄` 상태의 사용자 확인 절차(ADR-02)가 된다.
