# J5-081 화면 범위의 필지 경계·지번, 용도지역 한 줄

기록일: 2026-10-14. 사용자 지시: "1번 2번 순서로 진행해"(1번: 주변 필지 경계 항상 보이기, 2번: 주소·지번으로 찾기는 J5-082). J5-080 실기기 확인(종로5가 193-17 카드·경계)과 용도지역 원문 화면(`uname`·`dyear`·`dnum`·`sido_name`·`sigg_name`)을 받은 뒤. ADR-27 보정.

## 결과

- 격리 프레임(`web/app/vworld-frame.js`): 점에 더해 범위(BOX, 한국 범위·한 변 0.02° 이하)와 받을 수(1~1,000)를 검사해 받는다.
- `web/app/vworld.js`: `parseParcelsInBox`(범위 응답 → 필지 목록, 형식 이상은 건너뜀, 전체 수가 받은 수보다 많으면 `truncated`), `aroundQueryBox`(보이는 범위에 사방 25% 여유, 한 변 상한은 가운데 기준, 소수 6자리 반올림 뒤에도 상한 안), `zoningSummary`(실측 `uname`·`dyear` → "일반상업지역 (2023 고시)", 같은 이름은 한 번, 이름 없는 결과는 뺌). 다리(`createVworldBridge.request`)가 범위·받을 수를 넘긴다.
- `web/app/map.js`: 화면 범위 필지 층(`layer-around`, 가는 붉은 선)과 지번 층(18단계 이상, 필지가 글자보다 클 때). `setAround`, `zoom()`, `visibleBbox()`, 화면이 바뀔 때만 `onViewChange`.
- `web/app/main.js`: 배경 지도가 VWorld 기본 지도이고 확대 17단계 이상이면 지도가 멈춘 뒤 0.6초에 범위를 받는다. 다 받은 범위(최근 30개)는 다시 부르지 않고, 일부만 받은 범위는 기억하지 않는다. 필지는 화면에만(4,000개 상한, 오래된 것부터 버림). 배경 지도를 바꾸거나 끄면 다시 정한다. 조회 카드에 용도지역 한 줄(원문 목록은 접힌 칸 그대로).
- `web/sw.js`: 설치 때 앱 파일을 브라우저 HTTP 캐시를 거치지 않고 받는다(`cache: "reload"`). 거치면 이전 판 파일이 새 판 캐시에 섞일 수 있다(실기기에서 출처 글이 '사용자 지정 타일' 로 보인 원인 후보, 미확정).
- 앱 0.2.41.
- 시험
  - `tests/web/vworld.test.mjs`: 범위 응답 해석·건너뛰기·`truncated`, 용도지역 한 줄, 받을 범위(여유·상한·가운데). 받을 범위 시험이 반올림으로 한 변이 0.02° 를 넘는 것을 찾아 고쳤다(넘으면 격리 프레임이 거절한다).
  - `tests/web/lookup.e2e.test.mjs`: 카드의 용도지역 한 줄, 확대 전에는 범위 조회 없음, 확대하면 범위 조회(1,000)·경계 3개, 받은 범위 안에서는 다시 부르지 않음, 배경 지도를 끄면 경계를 지움.

- 리뷰 반영(PR #128, Codex 3건)
  - 받는 중(0.6초 넘게 걸릴 때) 지도를 또 움직이면 그 화면의 범위를 부르지 않고 넘어가, 끝난 뒤에도 그 화면이 비어 남았다. 받는 중에 온 요청은 기억했다가 끝난 뒤 한 번 더 정하고, 그릴 때는 받은 뒤의 화면 범위를 쓴다. 시험: e2e 에서 범위 응답을 늦추고 그사이 지도를 끌면 끝난 뒤 범위 조회가 한 번 더 나간다.
  - 4,000개 상한으로 오래된 필지를 버려도 그 범위를 받았다는 기록은 남아, 돌아가면 다시 받지 않았다. 필지를 버리면 받은 범위 기록도 버린다.
  - 아래 시트를 접고 펼쳐 보이는 영역이 바뀌어도 화면 변화로 치지 않아 새 범위를 받지 않았다. 화면 변화 판단에 덮개 두께를 넣는다.

## 데이터 사전에 없어 정한 값

- 범위 조회 시작 확대 17단계, 지번 18단계, 여유 25%, 한 변 0.02°, 한 번 1,000필지, 화면 4,000필지, 멈춘 뒤 0.6초.
