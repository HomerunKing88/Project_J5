# J5-055 필지 카드의 연도별 표

기록일: 2026-10-02. 폰에서 필지의 연도별 공시지가·거래·소유 변동(J5-047·053)은 필지 이력 화면 안에만 있었고, 한 해를 가운뎃점으로 이은 긴 글 한 줄로 보였다. 필지를 누르고 이력을 한 번 더 열어야 했고, 해마다 같은 칸을 눈으로 맞춰 읽기 어려웠다. 큰 목표("필지마다 연도별 정보·거래")의 폰 화면을 필지 카드에서 바로 읽히는 표로 바꾼다.

## 결과

- `web/app/view.js` `yearSummaryCells(r)`: 연도별 요약 한 줄(`parcelYearSummaryInfo` 의 줄)을 표의 칸으로. 공시지가(원/㎡ 글, 자료가 없으면 null)·전년 대비, 이 필지 거래 수(수집했을 때 "n건") 또는 모르는 사유(미수집·일부만 수집·범위 밖·모름), 보조 글(번지대 n·연결 n·수집 m/12개월, 일부만 받은 해는 n개월 시도), 그해 소유 변동일(월-일) 또는 "없음"·"자료 없음". 일부만 받은 해는 시도한 개월 수도 적는다. 값과 판정은 기존 요약과 같고 PC `db parcels-years` 규칙을 따른다. 이 폰의 요약 글 한 줄(`yearSummaryRow`)은 표의 줄 `title` 에 남긴다. 이 글은 PC `years_text` 와 같지 않다(PC 는 같은 필지의 마지막 거래 금액·날짜, 같은 기준연도 값 바뀜, 연결 0 까지 적는다). PC 와는 칸의 값으로 대조한다.
- 필지 카드: "연도별" 표(최근 5개 연도)와 "기록·거래 보기"(연도가 5개를 넘으면 "모든 연도(n개)와 기록 보기"). 공시지가가 바뀐 지점 목록(J5-030)은 접힘으로 옮겼다(정정 여부 안내는 그대로).
- 필지 이력: 연도별 요약을 같은 표로. 설명은 "표 읽는 법" 접힘에 둔다.
- 표: `<table>` 의 열 머리(`th scope=col`)와 줄 머리(연도, `th scope=row`), 숫자는 tabular-nums, 괘선 줄. 토지소유 정보를 주지 않은 표는 소유 열을 감춘다. 전년 대비는 오르내림을 색으로 칠하지 않는다(시세·가치 판단이 아니다).
- 앱 0.2.22 (`APP_VERSION`, `sw.js` 캐시, e2e 3곳). `sw.js` 앱 파일 목록은 그대로.
- 시험
  - `tests/web/view.test.mjs`: `yearSummaryCells`(전년 대비, 같은 필지·번지대·연결·수집 개월, 미수집·일부만·범위 밖·모름, 공시지가 자료 없음, 소유 변동일·없음·자료 없음).
  - `tests/web/app.e2e.test.mjs`: 가상 파생본 필지 1 의 카드 표와 필지 이력 표의 칸·`data-tx`·줄 글, 가로 스크롤 없음.
  - 새 시험은 고치기 전 코드에서 실패함을 확인했다(단위: 함수 없음, e2e: 카드에 표 없음).
- 리뷰 반영(PR #102): 줄 `title` 이 PC `years_text` 와 같은 글이라고 적었던 설명을 바로잡았다(위). 일부만 받은 해에 시도한 개월 수를 더했다.
- 별도 수정(같은 PR, 시험만): `ux.e2e` 의 지도 실패 단계가 대상 목록이 그려지기 전에 "기록" 버튼을 누를 때가 있었다(J5-054 에서 넣은 경합). 지도 실패 안내는 목록보다 먼저 뜨므로 목록 5줄을 기다린 뒤 누른다. 전체 시험 한 번에서 한 번 실패했고, ux e2e 4개를 동시에 돌려 같은 실패(`row-act[2]` 없음)를 재현한 뒤, 고친 시험을 5개 동시에 돌려 모두 통과했다. 앱 동작 변경은 없다.

## 데이터 사전에 없어 정한 값

- 필지 카드의 표에 보이는 연도 수: 최근 5개 (`PARCEL_CARD_YEARS`).
- 소유 변동일은 표에서 월-일로 줄여 쓴다(연도는 줄 머리에 있다). 그해 변동이 없으면 "없음", 토지소유 자료가 없으면 "자료 없음".

## 테스트 명령과 결과 (2026-10-02, 컨테이너 Linux, Python 3.11, Node 22)
