# J5-079 VWorld 기본 지도 켜기

기록일: 2026-10-14. 사용자 지시: "머지하고 진행해"(J5-078 1b 머지 뒤). J5-078 기기 시험에서 폰이 VWorld 배경 타일을 바로 받는 것을 확인해, 측정 결과와 상관없이 할 수 있는 배경 지도부터 앱에 넣었다. ADR-18 보정.

## 결과

- `web/app/tiles.js`: 미리 설정 `vworld_base`(VWorld 기본 지도, WMTS `Base/{z}/{y}/{x}.png`) `verified: "2026-10-14"`, `enabled: true`. 항공사진·항공사진+라벨은 확인 전이라 그대로 고를 수 없다.
- 설정의 배경 지도 제공자 목록에서 VWorld 기본 지도를 고를 수 있다. 인증키는 이전처럼 이 폰에만 저장하고 타일 주소에는 자리표만 둔다(서비스 워커가 요청 직전에 넣는다).
- 빈 지도에 '배경 지도 켜기' 버튼: 누르면 설정의 배경 지도 칸으로 가서 제공자가 비어 있으면 VWorld 기본 지도를 고르고 인증키 칸에 커서를 둔다. 저장은 사용자가 누른다.
- 리뷰 반영(PR #127, Codex P1): 타일 한 장의 응답 확인만으로 켜면 약관(대량 받기·보관 범위·호출 한도)을 확인하지 않은 채 '이 범위 미리 받기'(한 번에 최대 3,000장)를 쓸 수 있었다. VWorld 기본 지도에는 `prefetch: false` 를 두어 미리 받기를 하지 않고 이유를 안내한다. 지도를 움직여 본 타일의 저장(서비스 워커 캐시)은 이전 규칙 그대로이며, 이것도 막을지는 사용자가 약관을 보고 정한다. 시험: `tiles.test.mjs`(기본 지도 `prefetch` 거짓, 직접 입력 참), `demo.e2e`(키 저장 뒤 미리 받기를 누르면 이용조건 안내). 고치기 전 코드에서 e2e 가 실패한다(안내가 '범위를 정할 대상·필지가 없습니다').
- 앱 0.2.39 (`APP_VERSION`, `sw.js` 캐시, 캐시 고정값, e2e 5곳).
- 시험
  - `tests/web/tiles.test.mjs`: 켜진 제공자는 직접 입력·VWorld 기본 지도, 기본 지도의 주소(키는 자리표)·키 없으면 거절, 항공사진 두 가지는 고를 수 없음.
  - `tests/web/demo.e2e.test.mjs`: 빈 지도의 배경 지도 켜기 → 설정 화면·VWorld 기본 지도 선택·인증키 칸 커서, 키를 넣고 저장하면 "저장했습니다: VWorld 기본 지도…"(안내 글에 키 없음), 끄기.

## 미확인 변수

- 앱 지도 안에서 배경 타일이 실제로 깔리는지는 머지 뒤 폰에서 확인한다(기기 시험 페이지에서는 같은 주소의 타일을 받았다. 앱은 서비스 워커가 키를 넣어 보낸다).
- VWorld 약관의 캐시·오프라인 사용 범위와 호출 한도(ADR-18 경계, 사용자 확인 항목). 확인되면 기본 지도의 `prefetch: false` 를 지워 미리 받기를 연다.

## 남은 인수조건·후속 작업

- 사용자: 머지 뒤 폰에서 앱을 닫았다 열고(새 판 0.2.39) 빈 지도의 '배경 지도 켜기' → 인증키 넣고 '배경 지도 저장' → 현장 지도에 VWorld 지도가 깔리는지 본다.
- J5-078 2단계: 기기 시험 페이지 4번의 격리 프레임 JSONP·경계 그림 결과로 지도 탭 필지 조회를 만든다.
