## 사용자 기기·경로 (2026-09-26 기입)

실제로 읽은 값만 적는다. 출처가 없는 칸은 미확인으로 남긴다.

| 항목 | 값 | 출처 |
|---|---|---|
| PC OS | macOS (버전 미확인) | 사용자 진술. 버전은 `sw_vers` 출력으로 기입 |
| 로컬 클론 경로 | 미확인 | `pwd` 출력으로 기입 |
| 폰 OS·기종 | iPhone (기종 미확인), iOS 18.7 | J5-004 실기기 결과 (2026-09-23). 기종은 기록되지 않았다. 설정 → 일반 → 정보의 "모델 이름" 으로 기입 |
| 주 브라우저 | Safari 27.0 (WebKit 605.1.15) | J5-004 실기기 결과 |
| 폰→PC 파일 전송 방법 | '파일' 앱에서 공유 (AirDrop 계열) | J5-004 실기기 결과 |
| 백업 위치(PC와 독립) | 미확인 (외장 드라이브 미지정) | `ls /Volumes` 와 첫 `backup --dest` 결과로 기입 |
| `J5_DATA_HOME` 실제 경로 | `~/J5_DATA_HOME` (사용자 홈 폴더 아래) | 실거래 실측 3차(2026-09-23, 실행 `20260923-215249-cc7db5`) 실행 기록의 `key_source` 가 이 폴더의 `config.env` 였다 |
| 인증키 위치 | `~/J5_DATA_HOME/config.env` (`DATA_GO_KR_SERVICE_KEY`). 파일 권한은 미확인 | 위치는 J5-014 실측 2차·3차. 권한은 도구가 경고만 하며 실측 기록에 권한 확인값이 없다. `ls -l ~/J5_DATA_HOME/config.env` 결과로 기입하고 600 이 아니면 `chmod 600` |
| 정적 HTTPS 시험 경로 | 없음. 시험은 같은 Wi-Fi 의 `http://<Mac IP>:8000/` (`python -m http.server 8000 --directory web`) | J5-004 절차·결과. HTTPS 배포는 공급자 미정(ADR-01) |

계정 이름이 든 절대경로는 저장소에 적지 않고 홈 폴더 기준(`~`)으로 적는다. 남은 미확인 항목은 클론 경로, 외장 백업 위치, macOS 버전, iPhone 기종, `config.env` 파일 권한이다. 이것을 채우기 전에는 R0 표를 완료로 보지 않는다.
