# J5-027 필지 찾기: 지번·PNU 검색과 현재 위치

기록일: 2026-09-27. J5-025·026 으로 필지 수천 개와 속성·이력이 폰에 들어오자 지도를 손으로 움직여 필지를 찾기 어려워졌고, 임장 중 "여기가 어느 필지인가" 를 바로 알 방법이 없었다. ADR-20(현재 위치는 누를 때 한 번 읽고 저장·전송 없음)으로 채택했다.

## 결과

- `web/app/parcels.js`: `parseParcelQuery`(지번 "182-13"·"산1-2"·"동이름 182-13"·PNU 19자리, 끝의 지목 글자 무시), `findParcels`(불러온 필지 안에서만, 부번 생략 시 부번 0 우선, 동 이름은 앞부분 일치, 정렬·상한), `parcelAt`(위치가 든 필지). DOM·통신 없음.
- `web/app/map.js`: `focusParcel(pnu)` 필지 하나로 화면 맞춤(확대 상한 z19 `FOCUS_MAX_SCALE`, 이미 더 확대돼 있으면 유지), `setLocation` 현재 위치 점·정확도 원(`layer-locate`, 점 위·축척 아래 층, 탭 대상 아님). 위치는 렌더 상태로만 있고 저장하지 않는다.
- `web/app/main.js`·`index.html`·`styles.css`: 지도 화면에 "지번으로 필지 찾기" 입력(필지가 있을 때만 표시)과 결과 목록(여럿이면 최대 20개, 열기 버튼), "현재 위치" 버튼(Geolocation 없으면 비활성, 보안 컨텍스트 아니면 안내, 고정밀·15초·캐시 없음). 그 자리의 필지가 있으면 패널을 열고 "현재 위치는 ○○ 필지 안 (정확도 ±N m). 위치는 저장하지 않습니다", 없으면 범위 밖 안내, 권한 거부·실패는 원인별 안내. 범례 설명 문구. 앱 0.2.6, SW 캐시 v0.2.6.
- 테스트: `parcels.test.mjs` 검색·위치 1건, `app.e2e.test.mjs` 필지 찾기 절(하나 일치 → 패널·확대·포커스, PNU, 산 지번, 없음, 형식 오류)과 현재 위치 절(CDP 권한 허용 + 위치 흉내: 필지 4-2 안 → 패널·점·정확도 원, 범위 밖, 권한 거부).
- 문서: ADR-20, 릴리스 계획 J5-027, `web/README.md`, `tests/README.md`, 색인(J5-026 PR #72).

## 데이터 사전에 없어 정한 값

- 검색 규칙: 부번을 안 적으면 부번 0(본번만)을 먼저, 없으면 같은 본번 전체. 결과 상한 20. 동 이름은 앞부분 일치(코드도 허용).
- 필지 맞춤 확대 상한 z19(약 0.24 m/px). 위치 읽기 15초 제한, 정확도 원 반지름은 화면 5,000px 까지.
- 위치는 어디에도 저장하지 않는다(관측 기록·내보내기·IndexedDB 모두). 관측에 위치를 붙이려면 별도 ADR 과 사용자 승인이 필요하다.

## 리뷰 반영 (PR #73, Codex 2건)

- P1 타일 요청으로 위치 노출: 배경 타일이 켜져 있으면 현재 위치로 화면을 옮기지 않고(점·정확도 원은 현재 범위에서만, 필지 패널은 이동 없이 열기) 안내 문구에 이유를 적는다. e2e 에서 타일을 켠 뒤 위치를 흉내내 서버 타일 요청 수가 늘지 않는 것을 확인한다. ADR-20 경계에 기록.
- P2 지도 실패 시 검색: 찾기 폼 제출·현재 위치 버튼의 리스너를 지도 초기화 바깥에서 잇는다. e2e 의 지도 실패 단계에서 지번 찾기가 페이지 이동 없이 패널을 여는 것을 확인한다.

## 남은 인수조건·후속 작업

- 사용자: 실제 필지 파일을 넣고 지번 찾기와 현장에서 "현재 위치" 로 필지가 열리는지 확인한다.
- 후속 후보: 검색 결과에서 물건·거래 수 표시, 최근 찾은 필지 목록(기기 저장은 사용자 결정), 지역지구 코드→이름 표, 건축물대장 연결.
- 자동 테스트 통과는 실기기 검증이 아니다.
