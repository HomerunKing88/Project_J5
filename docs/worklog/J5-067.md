# J5-067 주변 사례 추이 그래프

기록일: 2026-10-13. 사용자 지시: "머지하고 다음 작업 진행". 큰 목표 "매매 이력과 근처 매각 사례를 통해 가격 적정성 검토" 의 다음 조각으로, 주변 사례(J5-064)의 단가를 시점별로 보이게 했다. 설계 결정은 ADR-25 보정.

## 결과

- `web/app/view.js`
  - `compsChartData(c, feature, { since, today })`: `nearbyComps` 결과에서 대지 평당 단가가 있는 사례를 점으로(지분·면적 없음은 빠짐, 오래된 것부터), 이 필지 공시지가를 원/㎡ × 평으로 바꿔 기준연도 1월 1일부터 다음 기준연도까지의 계단으로(기간 안만). x 범위는 기간 시작~오늘(전체 기간이면 점의 연도), y 범위·눈금은 1·2·5 단계(`niceTicks`, 0 아래로 내려가지 않음). 대지 평당이 있는 사례가 없으면 null.
  - `yearFrac`(날짜 → 연도 소수, 월만 알면 15일), `niceTicks`.
- 필지 카드 주변 사례(`web/index.html`·`web/app/main.js` `renderCompsChart`)
  - 자체 SVG(외부 코드 없음, `style` 속성 없음). 회색 실선 격자, 눈금 글자는 보조 글 색, 공시지가 선 끝에 "공시지가" 글자.
  - 점은 누를 수 있다(보이는 점보다 큰 24px 누름 영역, 키보드 초점 가능). 누르거나 초점을 주면 아래에 "날짜 · 종류 · 대지 평당 · 지번" 을 적는다.
  - 범례: 거래 점, 공시지가 선, 이 필지 거래가 있으면 "큰 점은 이 필지의 거래". 점마다 글자를 붙이면 이웃 점과 겹쳐(화면 확인) 범례로 옮겼다.
  - 그래프 값 표(접힘): 모든 점의 계약일·종류·대지 평당·지번. 공시지가 값은 연도별 표에 있다.
  - 기간·종류는 주변 사례와 같다(J5-066 의 종류 고르기를 따른다). 공시지가가 없으면 선 없이 그 사유를 적는다.
- 색(시각화 지침의 검증기 `validate_palette.js` 로 확인): 거래 점 `#2a78d6`(어두운 화면 `#3987e5`), 공시지가 선 `#eb6834`(`#d95926`). 앱의 시트 면(`#ffffff`·`#1b1f24`)에서 밝기 범위·채도·색각 이상 구분(ΔE 24.7·26.8)·일반 구분(33.6·31.8)·대비가 모두 통과. 처음 고른 앱 청색·보조 회색 조합은 어두운 화면에서 일반 구분 ΔE 12 로 기준(15) 미달이라 쓰지 않았다. `--chart-1`·`--chart-2` 토큰.
- 앱 0.2.32 (`APP_VERSION`, `sw.js` 캐시, e2e 5곳).
- 시험
  - `tests/web/view.test.mjs`: 연도 소수, 눈금, 점(지분·면적 없음 제외, 순서, 이 필지 표시, 평당 값), 기간 시작에 걸친 기준연도부터의 계단과 평당 환산, y 범위가 점·선을 덮음, x 눈금, 전체 기간의 x 범위, 공시지가 없음, 대지 평당 사례 없음.
  - `tests/web/ux.e2e.test.mjs` 13f: 연습용 거래 전체 기간에서 점 10개(대지 평당 10건과 같음), 연습용 필지에는 공시지가가 없어 선 없음과 제목의 사유, 값 표 10줄, SVG 에 style 속성 없음, 점을 누르면 값이 적힘, 토지만 고르면 점 1개.
  - 화면 확인: 390×844, 밝은·어두운 화면에서 공시지가 이력을 넣은 가상 필지로 캡처해 겹침·잘림을 봤다(시험 밖 임시 사본, 저장소에 넣지 않음).
  - 새 시험은 고치기 전 코드에서 실패한다(함수·화면 없음).

## 데이터 사전에 없어 정한 값

- 그래프 높이 180px(눈금 띠 포함), 왼쪽 눈금 폭 52px. 눈금은 4단계 남짓.
- 공시지가는 기준연도 1월 1일부터 다음 기준연도 전까지 같은 값으로 그린다(가격 기준일 1월 1일).

## 미확인 변수

- 거래가 많은 동(수십 건)에서는 점이 겹친다. 실자료로 보고 필요하면 기간을 줄이거나 종류를 고르게 안내한다.
- 대지 평당은 건물값이 든 거래와 토지 거래가 섞인 값이다(ADR-26). 종류 고르기로 나눠 볼 수 있다.
- 가상자료 시험이다. iPhone 실기기 확인이 아니다.

## 남은 인수조건·후속 작업

- 사용자: 공시지가 이력이 든 실제 PC 자료 파일로 관심 필지 몇 곳의 그래프를 보고, 공시지가 선과 거래 점의 간격이 동마다 어떻게 다른지 기록한다.
