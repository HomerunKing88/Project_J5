# J5-077 연습용 자료를 연습용 모드로 분리

기록일: 2026-10-14. 사용자 지시: 배포 주소 화면을 보이며 "가상필지 정보도 남아있고 … 실제 사용하는 서비스와는 거리가 너무 멀다", 이어서 고른 정리 항목 "가상 자료 제거". 같은 지시의 온라인 필지 조회는 J5-078(ADR-27)로 나눈다.

## 결과

- 연습용 모드: 주소에 `?demo=1` 을 붙여 연 폰에서만 연습용 자료 버튼(현장 시작하기의 "연습용 자료로 둘러보기", 설정의 연습용 대상·필지·배경)과 안내 글, 지도 범례의 연습용 대상이 보인다. `?demo=0` 으로 끈다. 켬 여부는 이 폰의 meta `demo_mode` 에 두어 주소의 값을 바꾸며 다시 열어도 유지된다. 감춤은 `body.demo` 가 없을 때 `.demo-only` 를 감추는 CSS 다.
- 기본 자료 종류: 저장한 적이 없으면 실제(`private_real`). 연습용 모드에서는 이전처럼 연습용. 실제 모드의 설정 화면에서는 연습용 종류를 고를 수 없다(이미 연습용으로 저장돼 남은 폰은 그대로 보인다).
- 상단 자료 종류 배지: 실제 자료이면 감춘다. 연습용일 때만 "연습용 자료" 로 보인다. 첫 그리기 전에도 감춰 둔다.
- 기존 폰 정리: 연습용 모드가 아닌 폰은 열 때마다 앱에 든 연습용 자료(대상·필지·윤곽·거래, 출처 `bundled_synthetic`)를 걷어 낸다. 범위는 J5-061 "연습용 자료 지우기" 와 같아 기록·사진·PC 자료 파일·이 폰이 만든 대상은 그대로다. 자료 종류가 연습용으로 저장돼 있고 연습용 기록이 하나도 없으면 실제로 바꾼다(`ui.js` `retireModeTo`). 연습용 기록이 남아 있으면 보내기 묶음이 갈리지 않게 그대로 둔다.
- 앱 0.2.37 (`APP_VERSION`, `sw.js` 캐시, 캐시 고정값, e2e 3곳).
- 시험
  - `tests/web/demo.e2e.test.mjs`(새 파일): 처음 실행은 배지 없음·연습용 버튼 없음·현장 시트에 "연습용" 글 없음·자료 종류 실제·연습용 종류 고를 수 없음·설정의 연습용 버튼 감춤, `?demo=1` 에서 연습용 자료로 둘러보기(대상 5곳)와 배지, 주소에 demo 가 없어도 연습용 모드 유지, `?demo=0` 에서 연습용 자료를 걷어 내고 자료 종류 실제·작업 공간 이름 유지·빈 상태 시작하기.
  - `tests/web/ui.test.mjs`: `retireModeTo`(연습용 기록이 남으면 그대로, 저장한 적 없으면 바꾸지 않음).
  - `tests/web/ux.e2e.test.mjs`·`app.e2e.test.mjs`: 첫 접속을 `?demo=1` 로(연습용 자료로 사용자 흐름을 시험하는 내용은 그대로).

## 데이터 사전에 없어 정한 값

- 연습용 모드 주소 값 `demo=1`/`demo=0`, meta 키 `demo_mode`.
- 기본 자료 종류를 실제로 둔 것. 정본·패키지의 `data_mode` 값과 규칙은 바꾸지 않는다.

## 테스트 명령과 결과 (2026-10-14, 컨테이너 Linux, Python 3.11, Node 22)

- `python -m pytest -W error::UserWarning` → 473 passed (63초).
- `node --test --test-timeout=300000 "tests/web/**/*.test.mjs"` → 105 pass (헤드리스 Chromium e2e 포함).

## 미확인 변수

- 배포 주소의 실제 iPhone 에서 새 판(0.2.37)을 받은 뒤 연습용 필지가 사라지고 배지가 없어지는지는 실기기로 확인한다. 가상 서버 시험이다.

## 남은 인수조건·후속 작업

- 사용자: 머지 뒤 배포 주소를 폰에서 다시 열어(새 판을 받으려면 한 번 닫았다 연다) 연습용 필지·배지가 없어졌는지 본다.
- J5-078: 지도의 아무 곳이나 눌러 필지를 바로 조회(온라인, ADR-27).
