# J5-082 주소·지번으로 찾기 (온라인)

기록일: 2026-10-14. 사용자 지시: "1번 2번 순서로 진행해" 의 2번. ADR-27 보정.

## 결과

- 격리 프레임(`web/app/vworld-frame.js`): 검색 요청(`api: "search"`)을 받는다. 검색어(1~80자, 꺾쇠·따옴표·제어문자 없음)와 분류(지번 주소 parcel·도로명 주소 road)를 검사하고 VWorld 검색 API(주소 검색, 경위도, 5건)를 JSONP 로 부른다. 만드는 주소는 데이터 API 와 검색 API 두 곳뿐이다.
- `web/app/vworld.js`: `createVworldBridge().search(query, key, domain, category)`, `searchQuery`(공백 정리·쓸 수 없는 글자 빼기·80자), `parseSearchResponse`(`result.items[]` 의 `point.x·y` 를 경위도로, 이름은 `address.parcel` → `address.road` → `title`. 한국 범위 밖·자리 없는 결과는 뺀다).
- `web/app/map.js`: `centerOn(lonlat, zoom)`(덮이지 않은 영역 가운데로, 덜 확대돼 있으면 그 단계까지).
- `web/app/main.js`·`index.html`: 찾기 칸을 가져온 필지가 있거나 배경 지도가 VWorld 기본 지도일 때 보인다. 가져온 필지에서 먼저 찾고 없으면 VWorld 주소 검색(지번 주소 → 없으면 도로명 주소). 하나면 그 자리로 옮겨 필지 조회 카드, 여럿이면 목록에서 고른다. 키 없음·오프라인·못 찾음·오류는 안내. 찾기 칸 글을 "주소·지번 (예: 종로5가 193-17)" 로.
- 앱 0.2.42.
- 시험
  - `tests/web/vworld.test.mjs`: 검색어 정리, 검색 응답 해석(이름 우선순위·범위 밖·자리 없음 빼기·없음·오류·형식 이상).
  - `tests/web/lookup.e2e.test.mjs`: VWorld 키가 있으면 찾기 칸, 주소로 찾으면 검색 요청(주소 검색·지번 주소·콜백)과 찾은 자리의 필지 조회·카드, 없는 주소는 지번·도로명 둘 다 찾고 안내.
  - `tests/test_web_static.py`: 격리 프레임의 주소는 검색·데이터 두 곳, 분류 검사.

## 미확인 변수

- VWorld 검색 API 의 JSONP(`callback`) 지원과 응답 필드 이름(`result.items[].point.x·y`, `address.parcel·road`). 실측 전이다. 다르면 '찾지 못했습니다' 로 끝난다.
- "193-17" 처럼 동 이름 없이 넣었을 때 VWorld 가 무엇을 돌려주는지.

## 남은 인수조건·후속 작업

- 사용자: 머지 뒤 찾기 칸에 "종로5가 193-17" 과 도로명 주소를 넣어 그 필지로 옮겨지는지 본다. 안 되면 찾기 칸 아래 안내 글을 알려 준다(필드 이름을 실측으로 고친다).
