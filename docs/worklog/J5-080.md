# J5-080 지도를 눌러 필지 조회 (온라인, ADR-27)

기록일: 2026-10-14. 사용자 결정: 온라인 조회로 전환(누른 자리의 좌표가 VWorld 로 전송되는 것 승인). J5-078 실측에서 폰의 격리 프레임 JSONP 가 VWorld 연속지적 응답을 받는 것을 확인해 앱 기능으로 넣었다. 설계 결정은 ADR-27.

## 결과

- `web/app/vworld.js`(새 파일)
  - `createVworldBridge`: 숨긴 격리 프레임(`vworld-frame.html`, `sandbox="allow-scripts"`) 하나를 두고 요청마다 번호를 붙여 보낸다. 그 프레임에서 온 응답만 받고 시간이 지나면 `timeout`.
  - `parseParcelResponse`: 실측 필드(`pnu`·`addr`·`jibun`·`jiga`·`gosi_year`·`gosi_month`)와 경계(경위도 MultiPolygon). PNU 19자리·한국 범위 좌표·꼭짓점 상한(20,000)을 검사하고 아니면 `bad_response`. 지번 뒤의 글자를 지목으로(`splitJibun`), 공시지가는 원/㎡ 숫자(없으면 null), 기준 연월, 도형면적(`polygonAreaM2`, 구멍 뺌). 앱의 필지 함수가 쓰는 모양(`feature`)도 만든다.
  - `parseZoningResponse`: 용도지역 속성을 이름 그대로(글·숫자만, 상한 12개). 필드 뜻은 실측 전이라 짐작하지 않는다.
  - 표기: `fmtJiga`(만 원/㎡ · 만 원/평), `fmtAreaPyeong`.
- `web/app/map.js`: 빈 곳을 누르면 `onTapMap([경도, 위도])`. 조회 필지 층 `layer-lookup`·`setLookup(polygons, bbox)`(화면은 옮기지 않는다).
- `web/app/main.js`·`index.html`: 지도 빈 곳 누르기 → 조회 카드(`#lookup-panel`). 배경 지도 키가 없으면 키 안내, 오프라인이면 안내, 조회 중 → 주소·필지 번호·지번·지목·공시지가·도형면적("경계로 계산, 공부면적 아님")·용도지역 원문(접힘)·"이 필지를 대상으로 기록". 필지 없음·VWorld 오류·연결 실패는 사유로. 늦게 온 응답은 마지막으로 누른 것만. 카드를 닫거나 다른 카드를 열면 경계도 지운다. 결과는 저장하지 않는다.
- `web/sw.js`: 앱 캐시에 `app/vworld.js`. 앱 0.2.40.
- 시험
  - `tests/web/vworld.test.mjs`(새 파일, 8개): 실측과 같은 구조의 응답 해석, 없음·오류·형식 이상, 값 없으면 null, 지번·지목 나누기, 도형면적과 구멍, 꼭짓점 상한, 용도지역 원문, 표기, 프레임 주고받기(sandbox 속성·다른 창 메시지 무시·실패 전달·닫기).
  - `tests/web/lookup.e2e.test.mjs`(새 파일): 키 없으면 VWorld 를 부르지 않고 안내, 배경 지도에 키 저장 뒤 지도를 누르면 카드(주소·PNU·지번·지목·공시지가·기준 연월·도형면적)·용도지역 원문·경계, 요청에 콜백·자료 이름·앱 주소, 격리 프레임 하나, 화면에 키 없음, 이 필지를 대상으로 기록 → 기록 화면·카드와 경계 지움, 필지 없는 자리 안내. VWorld 응답은 CDP 로 흉내.
  - `tests/test_web_static.py`: 앱 모듈도 격리 프레임만 쓰고 직접 요청·외부 주소 없음.

## 미확인 변수

- 실제 폰에서 지도를 눌렀을 때의 응답 시간과 카드 표시(기기 시험 페이지의 격리 프레임 조회는 약 1.2초).

- VWorld 이용약관의 호출 한도.

## 남은 인수조건·후속 작업

- 사용자: 머지 뒤 앱을 닫았다 열고(0.2.40) 설정의 배경 지도에 VWorld 키를 넣어 저장한 다음, 현장 지도의 아무 곳이나 눌러 카드의 지번·지목·공시지가와 경계가 맞는지 본다. 용도지역 원문을 열어 어떤 이름이 오는지 알려 준다(정리할 필드를 정한다).
- 후속: 용도지역 필드 정리, 토지 특성(공부면적·이용상황)은 NED API 의 JSONP 지원을 확인한 뒤.
