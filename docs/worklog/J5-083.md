# J5-083 직접 입력으로 켠 VWorld 배경의 확대 상한

기록일: 2026-10-14. 사용자 보고(폰 화면): "20m라고 표기되는 수준에서 더 확대하면 그림이 안나온다". 같은 화면의 출처 글이 "배경: 사용자 지정 타일" 이었다.

## 원인

- 폰의 배경 설정이 "직접 입력" 에 VWorld 기본 지도 주소(`https://api.vworld.kr/req/wmts/1.0.0/{key}/Base/{z}/{y}/{x}.png`)를 넣은 상태였다. 0.2.40 이전에는 기본 지도를 이렇게만 켤 수 있었다.
- 직접 입력은 확대 상한이 22 다. 그래서 확대 20단계 이상에서 VWorld 에 없는 단계의 타일을 요청했고, 실패한 타일은 감추므로 배경이 비었다. 기본 지도 설정(상한 19)이면 19단계 타일을 늘려 그린다.
- 같은 이유로 출처 글이 "사용자 지정 타일" 로 보였고, 주변 필지 경계(J5-081)와 온라인 찾기(J5-082)도 켜지지 않는다(둘 다 제공자가 기본 지도일 때만 켜진다). J5-081 에서 원인 후보로 본 서비스 워커 캐시는 이 문제의 원인이 아니었다.

## 결과

- `web/app/tiles.js` `resolveTileConfig`: 직접 입력 주소가 고를 수 있는 미리 설정 제공자의 주소와 같으면(호스트 대소문자 무시) 그 제공자 설정으로 돌려준다. 그 밖의 `api.vworld.kr` 주소(확인 전인 항공사진 등)는 직접 입력으로 두되 확대 상한을 19로 한다.
- `web/app/main.js` `loadTileSettings`: 저장된 직접 입력 설정이 기본 지도로 풀리면 제공자를 `vworld_base` 로, 주소 칸을 비워 저장한다. 인증키는 그대로 쓴다.
- 앱 판은 0.2.42 그대로다(아직 배포 전, PR #128 과 함께 나간다). 앱 캐시 잠금 파일만 다시 썼다.
- 시험
  - `tests/web/tiles.test.mjs`: 직접 입력의 기본 지도 주소 → `vworld_base`·상한 19·VWorld 출처·미리 받기 꺼짐, 호스트 대문자, 항공사진 주소는 직접 입력·상한 19, 같은 출처 타일은 상한 22, 확대 21단계에서 요청 단계 19.
  - `tests/web/ux.e2e.test.mjs` 13d-2: 예전 설정을 넣고 다시 열면 설정 화면이 기본 지도로 바뀌고 저장소 값도 바뀌며 출처 글이 VWorld 로 보인다.
